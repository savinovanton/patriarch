# GDD 05 — Религия и Церковь

> Статус: **черновик v0.1**. Числа помечены **[предл.]**; исторические факты, в которых нет уверенности, помечены **[проверить]**.
> Покрывает: FR-REL-1…6, часть FR-DYN-4 (церковные правила брака), часть FR-THR (Церковь как фракция и благословение на престол), ECO (вера населения).
> Эпики: **E31** (религия и Церковь), частично **E7/E8** (брак, вера персонажей), **E20/E34** (фракции, Совет), **E22** (события).
> Зависимости: GDD 01 (брак, духовные связи), GDD 02 (Церковь и престол, сценарий «Церковный раскол»), GDD 03 (вера населения, церковные земли, секуляризация), GDD 04 (духовник, исповедь, церковные должности).
> Религия — **отдельная система** (решение владельца): род может поддержать Церковь, отколоться, принять иную веру или основать собственную Церковь.

## 1. Назначение

Вера в сеттинге 1703 года — не фон, а **политика, налоги, браки и бунты одновременно**. Система должна давать:

1. **Выбор рода**, у которого есть цена и последствия: поддержать официальную Церковь, отколоться, сменить веру, создать свою.
2. **Церковь как актор** со своими интересами, землями, иерархией и расколами.
3. **Связность с остальным**: легитимность и благословение на престол, настроения сословий, браки, схемы (исповедь), сценарий «Церковный раскол».
4. **Ограниченную сложность**: конфессии — данные, догматы — выбор из набора; компактное состояние (ADR-0002).

**Опыт игрока:** «Патриаршество вакантно, Церковью управляет местоблюститель. Мой род — сторонник возрождения патриаршества, но император склоняется к Синоду. Старообрядцы в моих вотчинах платят двойную подать и бегут за Урал. Если я их защищу, потеряю милость, но получу купеческие деньги и верных людей. А если создать собственную церковь…»

## 2. Основные сущности

| Сущность | Что это |
|---|---|
| **Вера (Faith)** | Конфессия: название, догматы (набор выбранных вариантов), правила брака, отношение к государству и иноверцам |
| **Официальная Церковь** | Господствующая Церковь империи как политический актор |
| **Позиция рода (Stance)** | Отношение династии к вере и Церкви (4 пути) |
| **Иерарх** | Персонаж уровня A на церковной должности (митрополит, епископ, настоятель) |
| **Община / доля веры** | Доля вер в провинции (GDD 03) |
| **Миссионер** | Слуга/персонаж, распространяющий веру |
| **Благосклонность Церкви** | `church_favor[dynasty]` 0…100 — отношение иерархии к роду |

## 3. Веры (конфессии)

### 3.1 Базовый набор [предл.]

| Вера | Где | Особенности |
|---|---|---|
| **Православие (официальная Церковь)** | Вся страна | Господствующая; иерархия, монастыри, земли; в 1703 г. патриаршество вакантно |
| **Старообрядчество** | Север, Поволжье, Урал, Дон, окраины | Ответвления **поповцы** (со священством) и **беспоповцы** (без священников); гонимо; крепкие общины, купеческие деньги |
| **Лютеранство** | Прибалтика, Немецкая слобода, иноземцы | Терпимо государством, связь с иностранными специалистами |
| **Католичество** | Украина/Белоруссия (влияние Польши), иноземцы | Подозрительно для двора, сильные связи с Польшей |
| **Ислам** | Татары, башкиры | Привилегии ясачных, свои обычаи, связь с Крымом/Османами |
| **Буддизм** | Калмыки, буряты | Кочевники, связь с Тибетом |
| **Язычество / шаманизм** | Народы Сибири | Миссионерская работа, ясак |

Не все веры доступны родам: большинство русских родов могут выбрать **поддержку, раскол или (очень дорого) переход в лютеранство/католичество**; остальные веры — для инородческих групп и опциональных родов (M2).

### 3.2 Структура веры

```
faith {
  id, name, symbol, color,
  tenets { authority, rite, clergy, state_attitude, others_attitude, marriage, asceticism, learning },
  rules { forbidden_degree, consent_required, mixed_marriage_policy, max_marriages },
  state_status: official | tolerated | persecuted | forbidden,
  capital/centres: [provinces/holy sites]
}
```

### 3.3 Догматы (tenets) — набор выбора [предл.]

Веры задаются набором категорий; в каждой категории — несколько вариантов с модификаторами.

| Категория | Варианты (примеры) | Эффекты (примеры) |
|---|---|---|
| **Власть** | Патриарх / Синод под государством / Старцы общины / Харизматический наставник | Подчинение императору, независимость, единство |
| **Обряд** | Древний обряд / Исправленный обряд / Собственный | Отношение старообрядцев, приём в Церкви |
| **Духовенство** | Женатые белые священники / Монашество / Без священства | Влияние духовенства, приходы, налоги |
| **Отношение к государству** | Послушание / Раздельность / «Царь-антихрист» | Лояльность, склонность к бунту |
| **Отношение к иным** | Терпимость / Исключительность | Миссии, конфликты, браки |
| **Брак** | Строгие правила / Умеренные / Свободные | Разрешённая степень родства, число браков |
| **Аскеза** | Строгие посты / Умеренно | Благочестие, расходы, настроения |
| **Знание** | Книжность и школа / Традиция | Образование, грамотность, способности клириков |

Каждый вариант: цена в очках, модификаторы, ограничения (несовместимости). У базовых вер набор фиксирован; у **собственной Церкви** игрок собирает набор в пределах бюджета очков (§6).

## 4. Официальная Церковь (актор)

### 4.1 Состояние

| Поле | Описание |
|---|---|
| `head` | Патриарх / местоблюститель / президент Синода (в 1703 г. — местоблюститель; исторически Стефан Яворский [проверить]) |
| `vacancy` | Флаг вакантности патриаршества (старт сценария) |
| `authority` | 0…100 — влияние на общество и двор |
| `unity` | 0…100 — единство иерархии |
| `wealth` | Доходы с церковных/монастырских земель (GDD 03) |
| `state_dependence` | 0…100 — насколько Церковь зависима от государства |
| `lands` | Провинции/доли церковных земель |
| `factions` | Внутренние течения (см. 4.2) |
| `agenda` | Список целей Церкви |

### 4.2 Внутренние течения

| Течение | Позиция |
|---|---|
| **Ревнители патриаршества и старины** | Восстановить патриаршество, защитить права, против вмешательства государства |
| **Учёные реформаторы (киевская школа)** | Образование, порядок, приемлют реформу; частично поддерживают императора |
| **Государственники** | Подчинение Церкви государству, Синод |

Численность и сила течений меняются событиями, назначениями и интригами. Они голосуют в Церковном совете и влияют на агенду.

### 4.3 Повестка Церкви

Церковь выбирает цели по состоянию:
- избрание/возрождение патриарха (требует согласия императора);
- сопротивление секуляризации и контролю над доходами;
- борьба с расколом и ересью (запрос на гонения);
- просвещение и школы;
- миссионерская работа (Сибирь, инородцы);
- благословение/осуждение императора и претендентов.

### 4.4 Отношения Церкви и государства

`state_dependence` растёт от реформ императора (Синод, контроль доходов, назначения); падает при усилении Церкви и в кризис. Исторические «якоря» (для настройки; уточнить даты по источникам): восстановление приказа по надзору за монастырскими доходами (≈1701) [проверить], указ о бородах и платье (≈1705) [проверить], учреждение Синода вместо патриарха (≈1721) [проверить].

### 4.5 Благосклонность Церкви к роду

`church_favor[dynasty]` — растёт от пожертвований, постройки церквей, защиты веры, службы Церкви, браков в ладу с каноном; падает от гонений, ереси, нарушения постов, нападений на духовенство, незаконных браков.
Влияет на: благословение для претензий (GDD 02), настроения верующих, готовность иерархов служить роду (духовник, епископ), снятие церковных запретов (разрешение на брак).

## 5. Позиция рода (4 пути)

У династии есть позиция (`stance`), которая определяет доступные действия, модификаторы и риски. Смена — **крупное решение** с ценой, временем и охлаждением (≥ 5 лет [предл.]).

### 5.1 Поддержка официальной Церкви (по умолчанию)

- **Бонусы:** `church_favor` ↑; благословение на претензии (`w_church`); поддержка духовенства в владениях; налоговые привилегии церковным землям; разрешения на браки проще.
- **Обязательства:** пожертвования (расход), постройка церквей, поддержка гонений по просьбе (политика), принятие назначений иерархов.
- **Подпозиции** (определяют фракцию): **патриаршист** (за возрождение патриаршества) / **синодальник** (за подчинение Церкви государству) / **нейтрал**. Влияет на отношения с императором и Церковью.

### 5.2 Раскол (старообрядчество и иные течения)

- **Выбор ветви:** поповцы (со священством; нужны беглые священники) или беспоповцы (без священства; община наставников).
- **Бонусы:** поддержка крестьян/посада/казаков из долей старообрядцев в владениях; деньги купцов-единоверцев; сплочённые общины, высокая верность.
- **Риски:** преследование государством (двойная подать, штрафы, аресты) [проверить: решения 1716 г.], потеря милости императора, закрытие должностей, события «гарей» (самосожжений), восстания; Церковь объявляет еретиками.
- **Скрытность:** род может быть **тайным** старообрядцем (скрывает) или **открытым**; тайность — новый вид секрета (GDD 04 §11); разоблачение — скандал.
- Старообрядческие общины — **не армия**; их сила — настроения и деньги.

### 5.3 Смена веры (переход)

- Доступные пути для русского рода: **лютеранство, католичество** (в M2 — ислам/иные для инородческих родов).
- **Условия:** доступный носитель веры (миссионер, пастор), иностранные связи, причина (брак, политика).
- **Процесс:** глава рода принимает новую веру (событие), остальные члены следуют с задержкой и сопротивлением; бывшая Церковь **отлучает** (`church_favor` → 0, запрет на браки с православными), население провинций реагирует (протесты, бегство).
- **Цены:** честь −(очень много), мнение двора ↓, шанс на престол близок к нулю (если не отменить иным путём); плюс: связи с иностранными державами, деньги, технологии (иностранные специалисты).

### 5.4 Основание собственной Церкви

Самый амбициозный путь (см. §6 подробно): новая вера с собственным набором догматов, символикой и иерархией.

## 6. Основание собственной Церкви

### 6.1 Условия

- `honor` рода ≥ **порог** [предл.: «знатный»];
- **Основатель:** член рода или приглашённый наставник с `piety` ≥ 70 и навыком Учёности ≥ 10 [предл.];
- казна ≥ **стоимость основания**;
- **последователи:** минимум 3 провинции (владения рода или единоверцы) с долей будущих верных ≥ 10% [предл.] (стартовая паства — из старообрядцев, раскольников, отдельных общин, либо из православных через проповедь);
- не быть под отлучением активной Церкви с чёрным списком (в исключениях).

### 6.2 Этапы

1. **Проповедь (12–24 месяца).** Длительный проект (как схема): наставник проповедует, собирает паству; риск раскрытия/преследования. Прогресс — число верных, ослабление существующих Церквей.
2. **Признание.** Реакция официальной Церкви и императора: объявить ересью, терпеть, или преследовать. Событие выбора для игрока.
3. **Устроение.** Выбор догматов в пределах бюджета очков (§3.3), названия, символики (цвет и значок на карте), структуры иерархии (должности внутри новой Церкви), рубежей (святых мест).

### 6.3 Бюджет догматов

Бюджет очков: `budget = base + f(honor) + f(piety основателя)` [предл.: 10–16]. Каждый вариант тратит очки или возвращает (ограничение за возврат — «бремя»). Несовместимости: например «Без священства» нельзя сочетать с «Женатые белые священники».

### 6.4 Что даёт и чем рискует

- **Даёт:** независимую иерархию (должности для членов рода), `church_favor` внутри новой Церкви, лояльность паствы, возможность прибавить к собственной претензии «благословение» и «выборный» голос верных; влияние на браки и политику; ресурсы пожертвований.
- **Рискует:** преследование государством (если вера «запрещена»), раскол внутри новой Церкви (течения), потеря милости императора, конкуренция с другими родами, внешнее давление.

### 6.5 Распространение новых вер

Другие династии могут **принять** вашу веру (по утилите и убеждению); вера распространяется миссионерами, браками, патронажем. Верующих ведёт **доля веры** в провинциях (§7). Лимит новых вер в мире [предл. ≤ 6–9 в партии] — ограничивает сложность и нагрузку.

## 7. Вера населения и её динамика

### 7.1 Состояние

В каждой провинции хранится **вектор долей вер** (≤ 6 вер активных) — `faith_share[province][faith]` (`Fixed`, сумма = 1). Доли можно задавать по группам (GDD 03) в M2; в MVP — на провинцию.

### 7.2 Динамика (раз в месяц, со сдвигом `id % 28`)

```
Δshare[f] = missionary_pressure[f] + owner_policy[f] + diffusion(neighbors)[f]
          + persecution_shift[f] + events[f] − erosion
```
- **Давление владельца:** вера владельца и политика терпимости (GDD 03 §9);
- **Миссионеры:** слуги/персонажи, закреплённые за провинцией;
- **Диффузия:** лёгкая подтяжка от соседних провинций;
- **Преследование:** выдавливает общины в бегство (миграция → окраины), массовые переходы, подавление; растёт скрытность вер;
- **События:** гари, проповеди, чудеса, указы.

Пороги: доля веры > 0.5 → вера «господствующая» в провинции (влияет на события, настроения, браки); 0.1–0.5 — заметное меньшинство; < 0.1 — малая община.

### 7.3 Настроения и экономика

- Конфликт веры владельца и населения снижает настроения групп (GDD 03 §4.2) и повышает `unrest`.
- Старообрядческие общины при преследовании: двойной налог (доход ↑), настроения ↓↓, миграция ↑.
- Церковные земли: доходы Церкви (GDD 03), политика секуляризации (§9).

## 8. Вера персонажа

### 8.1 Благочестие

`piety` 0…100 — личное благочестие (новое поле персонажа GDD 01). Растёт от молитвы, паломничества, милостыни, духовника, воспитания; падает от грехов (убийство, прелюбодеяние, обман), стресса.
Влияет на: отношения с духовенством, шанс на «чудо» (события), стабильность в стрессе, способность быть основателем Церкви.

### 8.2 Личная вера

Личная вера обычно совпадает с позицией рода; возможны **отступники** (члены рода, тайно или открыто придерживающиеся другой веры). Черты: «Набожный», «Святоша», «Вольнодумец», «Раскольник», «Лютеранин-в-тайне» и т.д. Последствия: лояльность к главе, шанс доноса, репутация.

### 8.3 Связь с интригами

Духовник (GDD 04) — источник секретов и оружие шантажа; исповедь и её нарушение — особый случай (GDD 04 §11).

## 9. Церковь и государство: политики

Политики (на уровне империи; игрок влияет через Совет и интриги):

| Политика | Эффект |
|---|---|
| **Надзор за церковными доходами** | Доходы казне ↑; `state_dependence` ↑; недовольство Церкви |
| **Секуляризация монастырских земель** | Земли переходят казне/роду-получателю (GDD 03); сильный конфликт с Церковью, развод фракций |
| **Возрождение патриаршества** | Церковь сильнее; `state_dependence` ↓; недовольство государственников |
| **Учреждение Синода** | Церковь управляется государственным органом; единство ↓, зависимость ↑ |
| **Терпимость к иноверцам** | Стабильность иностранцев ↑, недовольство Церкви ↑ |
| **Преследование раскола** | Двойной налог, аресты, давление; бунты, бегство, купеческие деньги уходят |
| **Миссионерская программа** | Расширение доли православных в Сибири/у инородцев; затраты |

## 10. Церковь и престол

- **Благословение:** `w_church` в `claim_strength` (GDD 02 §6.2): официальная Церковь благословляет претендента при совпадении интересов. Без благословения — штраф.
- **Миропомазание/коронация:** церемония как событие, завершающая успешный переворот или наследование.
- **Осуждение:** Церковь может **отлучить** императора/претендента/рода — тяжёлый удар по легитимности и настроениям, но влияние зависит от `authority` и единства Церкви.
- **Сценарий «Церковный раскол»** (GDD 02 §11.1): вакансия патриаршества, борьба течений, давление на старообрядцев, ответ императора; стартовые значения: `church.unity` = 45, `state_dependence` = 55, старообрядческие доли в нескольких провинциях выше обычных.

## 11. События

Примерный список групп событий (данные, FR-EVT-3):
- избрание/назначение иерархов, спор о патриаршестве;
- проповедь раскольника, пожертвования купцов-старообрядцев, гарь (самосожжение общины);
- приезд иностранных священников/пасторов, споры о крещении;
- паломничество, чудо, икона — только как редкие события, без отдельной механики святынь (решено);
- указ о бородах/платье, реакция ревнителей;
- поступок духовника (тайна исповеди);
- миссия в Сибирь, крещение инородцев;
- переход члена рода в иную веру;
- отлучение, анафема, прощение;
- основание новой Церкви: проповедь, признание, устроение.

**Подача насилия (решено):** гонения, гари, казни описываются **текстом и сдержанно, без натурализма**; иллюстрации — гравюры и символика, без жёстких сцен; летопись фиксирует факты.

MVP: ~15 событий; полный объём — в E22 (контент).

## 12. ИИ

- **ИИ Церкви:** выбирает повестку по состоянию: утилита с гистерезисом; реагирует на секуляризацию, гонения, кризис.
- **ИИ рода:** выбирает позицию по утилите: набожность, обиды на государство, финансовые стимулы (купцы-единоверцы), давление императора, окружение, браки; смена позиции — редкая и дорогая.
- **Основание Церкви ИИ:** крайне редко (через сценарные события), лимит в мире.
- LOD: далёкие роды пересчитывают позицию раз в N месяцев.

## 13. Интерфейс

| Окно / режим | Содержание |
|---|---|
| **Церковь** | Состояние (авторитет, единство, зависимость, вакансия), течения, иерархи, земли, повестка |
| **Моя вера и позиция** | Позиция рода, `church_favor`, обязательства, возможности смены |
| **Веры** | Список вер, догматы, правила, статус, распространение (карта) |
| **Основание Церкви** | Мастер: условия, этапы, выбор догматов в пределах бюджета очков, название и символика |
| **Миссии** | Миссионеры, цели (провинции), результаты |
| **Режимы карты** | Доли вер (цвета), господствующая вера, преследование, церковные земли |

Тултипы раскрывают влияние догматов и долей вер на настроения и шансы; ценообразование основания — с разбивкой.

## 14. Производительность и данные

- Вер в игре ≤ 16 (7 базовых + ≤ 9 пользовательских/созданных) [предл.].
- Доли вер: ≤ 400 провинций × ≤ 6 активных вер × `Fixed` (≈ 10 КБ).
- Обновление долей — раз в месяц, со сдвигом `id % 28`, диффузия по списку соседей.
- Состояние Церкви — маленькое (десятки полей); иерархи — персонажи уровня A (≤ ~30 живых).
- Догматы, правила, события — данными (FR-DATA-1).
- Бюджеты [предл.]: месячное обновление вер ≤ 1 мс; пересчёт позиции ИИ-рода ≤ 0.2 мс на род.

## 15. Тесты и критерии приёмки

### 15.1 Симуляционные тесты

- 50 лет без игрока: доли вер в провинциях остаются нормированными (сумма = 1) и не уходят в вырождение; господствующая вера меняется только при событиях/политиках;
- пользовательские веры не превышают лимит; созданная вера получает ненулевое распространение при активной миссии и затухает без неё;
- детерминизм: seed + команды → одинаковые вектора долей вер.

### 15.2 Приёмочные сценарии

- **REL-A1.** *Дано:* род в поддержке Церкви, `church_favor` 60. *Когда:* претензия на престол. *Тогда:* `w_church` положителен; тултип показывает вклад благословения.
- **REL-A2.** *Дано:* род переходит в старообрядчество (поповцы). *Тогда:* `church_favor` → 0, милость императора ↓, поддержка в провинциях с долей старообрядцев ↑, события гонений.
- **REL-A3.** *Дано:* род принимает лютеранство. *Тогда:* отлучение; браки с православными блокированы; честь ↓ значительно; открываются иностранные связи.
- **REL-A4.** *Дано:* основатель с `piety` 80, казна достаточна, 3 провинции с верными. *Когда:* старт проповеди. *Тогда:* прогресс идёт 12–24 мес; по завершении — выбор догматов и образование новой веры.
- **REL-A5.** Политика «секуляризация»: земли переходят; Церковь теряет `wealth`, `state_dependence` ↑, `unity` ↓, возможны бунты духовенства.
- **REL-A6.** Преследование раскола: двойной налог повышает доход, но настроения ↓ и миграция ↑ в провинциях с долей старообрядцев.
- **REL-A7.** Брак православного с лютеранкой без перехода: команда отклоняется с понятной причиной (GDD 01 §7.3).

### 15.3 Инварианты

- сумма долей вер в провинции = 1; доля ≥ 0;
- у каждой веры есть валидный набор догматов (без несовместимостей) и правила;
- ссылки на веры существуют; число вер ≤ лимита;
- `church_favor`, `authority`, `unity`, `piety` в границах;
- позиция рода всегда соответствует существующей вере.

## 16. Границы MVP (M1)

**Входит:** официальная Церковь как простой актор (вакансия, авторитет, единство, зависимость, повестка из 3 целей), 2 веры (православие, старообрядчество в одной ветви), позиции: **поддержка** и **раскол**, `church_favor`, благословение в претензиях, доли вер в 20 провинциях (одна ось: православные/старообрядцы), политика «преследование/терпимость», `piety`, ~15 событий, окно «Церковь» и режим карты «вера».

**Не входит в M1 (M2):** смена веры на другие, основание собственной Церкви (E31 целиком), все 7 вер, течения внутри Церкви, миссии, политика секуляризации, отлучение, подпозиции патриаршист/синодальник, вера по группам населения.

## 17. Принятые решения

| # | Вопрос | Решение |
|---|---|---|
| 1 | Вымышленные конфессии | ✅ **Да, серьёзно и без пародии** — часть альтернативной истории, тон уважительный (§6) |
| 2 | Не-православные роды | ✅ **В MVP только группы населения**; роды (татарские, калмыцкие, башкирские) — в M2 (§3.1, §16) |
| 3 | Ветви старообрядчества | ✅ **Две: поповцы и беспоповцы** (§5.2) |
| 4 | Святыни и паломничество | ✅ **Не делаем как механику.** Монастыри и церкви остаются зданиями (GDD 03); паломничество и чудеса допустимы только как редкие события без отдельной системы (§11) |
| 5 | Религиозное насилие | ✅ **Текстом и сдержанно, без натурализма** — события и летопись описывают гонения, гари, казни сдержанно; иллюстрации — гравюры без жёстких сцен (§11) |
| 6 | Исторические даты политик | ⏳ **Остаётся задачей проверки по источникам** (приказ по монастырским доходам ≈1701, указ о бородах ≈1705, двойная подать ≈1716, Синод ≈1721); до проверки в данные не вносим точные даты |
