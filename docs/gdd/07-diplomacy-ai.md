# GDD 07 — Дипломатия и ИИ династий

> Статус: **черновик v0.1**. Числа помечены **[предл.]** — стартовые значения для настройки.
> Покрывает: FR-DIP-1…4, общую архитектуру ИИ (ADR-0002 P6), единый интерфейс ИИ-акторов (династии, император, Церковь, армии).
> Эпики: **E15** (дипломатия и претензии), **E17** (ИИ династий), частично **E2** (бенчмарки/стресс-тесты ИИ), **E32** (внешний мир).
> Зависимости: GDD 01 (браки, честь), GDD 02 (император, фазы кризиса, блоки), GDD 03 (владения, претензии на земли), GDD 04 (услуги, милость, схемы, секреты), GDD 05 (позиции по вере), GDD 06 (армии, фронты).
> Решения ТЗ: внешние державы **не акторы** (FR-DIP-4) — дипломатия здесь только **между родами** внутри страны; ИИ — **без скрытых читов** по умолчанию.

## 1. Назначение

Роды должны вести себя как **люди с памятью и интересами**, а не как случайные генераторы событий. Система должна давать:

1. **Живую сеть отношений**: союзы, обиды, долги, браки, вражда — видимые и объяснимые.
2. **Дипломатию без войны**: пока страна не в гражданской войне, договариваются, торгуются, интригуют и подают иски, а не воюют.
3. **ИИ с понятными мотивами**: игрок видит причины и может на них влиять.
4. **Устойчивую производительность и детерминизм**: бюджеты ИИ в детерминированных единицах работы, LOD по близости к игроку и кризису (ADR-0002).

**Опыт игрока:** «Голицыны долго были моими союзниками, но я не выдал дочь за их наследника — и они стали искать Нарышкиных. Император подозревает сильнейших, поэтому союзы идут против меня. Предложить мировую, выдать заложника или пойти на компромисс?»

## 2. Сущности

| Сущность | Что это |
|---|---|
| **Отношение (Relation)** | Пара «род — род» с мнением, доверием, страхом, обидами, договорами |
| **Мнение (Opinion)** | Числовая оценка −100…100, составленная из модификаторов |
| **Доверие (Trust)** | 0…100: репутация надёжности партнёра (нарушал ли договоры) |
| **Обида (Grudge)** | Накопленная неприязнь с причиной и сроком затухания (GDD 04 §10.3) |
| **Договор (Treaty)** | Соглашение с условиями, сроком и последствиями нарушения |
| **Претензия (Claim)** | Основание требовать землю/должность/право (престол — GDD 02) |
| **Предложение (Offer)** | Входящий/исходящий запрос с ответом «да/нет/встречное» |
| **Агент ИИ (AI Agent)** | Модуль принятия решений для актора (род, император, Церковь, армия) |

## 3. Отношения между родами

### 3.1 Хранение

Отношения **разрежены**: запись существует только для значимых пар (родство, соседство, договор, обида, фракция, должность, вера) — не более **K = 40** на род [предл.]. Для остальных пар мнение считается «на лету» по базовой формуле без хранения.

```
relation(a, b) {
  opinion_mods [ { reason, value, decay, expires } ],   // разложение для тултипа
  trust 0..100, fear 0..100 (оценка силы b для a), 
  grudge [ { cause, severity, since } ],
  treaties [ids], favors_owed (GDD 04 услуги)
}
```

### 3.2 Мнение

```
opinion = base_by_kinship_and_faction
        + Σ opinion_mods (подарки, услуги, браки, совместная служба)
        − Σ grudges (по тяжести)
        + treaty_bonus
        ± faith_alignment (GDD 05)
        ± rank_difference_effect
        ± emperor_pressure (если император велел «не дружить»)
```

Каждое слагаемое — с причиной и сроком затухания (6–60 мес. [предл.]); тултип показывает полный список («Мнение ... из-за: ...»).

### 3.3 Доверие и страх

- **Доверие** падает при нарушении договоров, предательстве союзника, раскрытом заговоре против партнёра; растёт медленно от выполнения обязательств. Влияет на готовность заключать договоры и их условия.
- **Страх/уважение** — оценка силы партнёра (честь, армии, милость императора): сильный получает уступки, слабый — давление; влияет на то, кого «боятся» в Совете.

## 4. Договоры

### 4.1 Типы [предл.]

| Договор | Условия | Выгода сторонам | Нарушение |
|---|---|---|---|
| **Брачный союз** | Брак членов родов (GDD 01) | Честь, наследники, связи | Пострижение/развод → доверие −, обида |
| **Союз (взаимная поддержка)** | Поддержка голосов в Совете, в кризисе — вступление в один блок | Вес в Совете, защита | Измена в блоке → доверие −−, вражда |
| **Залог мира (упрощённый, без людей)** | Денежный/имущественный залог (деньги, право на пошлины, часть доходов) на срок | Стабильность отношений | Нарушение → потеря залога, `trust` −, обида. Заложников-людей (аманатов) в игре нет (решено) |
| **Договор поддержки претензии** | Один поддерживает претензию другого | Голоса, ресурсы | Отказ от поддержки → доверие − |
| **Патронаж (формальный)** | Покровительство клиента | Должности, защита / голос и услуги | См. GDD 04 §5.3 |
| **Торговый договор** | Взаимные пошлины/доступ | Доходы (GDD 03) | Нарушение → доверие −, потеря пошлин |
| **Мировая (соглашение о примирении)** | Условия урегулирования обиды | Сброс части `grudge` | Повторная обида → вражда сильнее |

### 4.2 Структура

```
treaty {
  id, type, parties [a, b, (c...)],
  terms { ... },                // параметры по типу
  duration | indefinite,
  public: bool,                  // публичный/тайный
  penalties { honor, trust, grudge, custom }
}
```

- Лимит активных договоров на род: **≤ 8** [предл.].
- **Тайные** договоры (союзы против императора, тайные браки/сговор) видны только сторонам и тем, кто раскрыл их шпионажем (GDD 04).
- Нарушение публичных договоров видно всем — репутационный удар.

### 4.3 Согласие на договор

```
accept_score = w_opinion × opinion + w_trust × trust + w_value × выгода_условий
             + w_power × (fear_of_proposer − arrogance)
             + w_goal × совпадение_с_целями + w_emperor × давление_императора
             − w_risk × риск − w_grudge × обиды
```

Если `accept_score ≥ порог` — согласие; иначе отказ с причиной (3 главных фактора) или встречное предложение. Порог зависит от характера главы (подозрительный, жадный, верный, честолюбивый). Решение **объяснимо** игроку.

## 5. Претензии и тяжбы

Под имперской властью роды не ведут частных войн (GDD 06 §10); споры идут **правовым путём**.

### 5.1 Основания претензий

| Тип | Источник |
|---|---|
| **Земли (на провинцию)** | Старая жалованная грамота, приданое, наследство, выкуп, займ, долг |
| **Должность** | Родовая традиция, обещание императора, заслуга |
| **Права и привилегии** | Привилегия торговли, пошлины, суд |
| **Опека/регентство** | Родство, завещание (GDD 01 §6.3) |
| **Престол** | GDD 02 §6 |

Претензии создаются **событиями, браками, наследством, документами** (грамоты — предметы в данных) и хранятся в записи персонажа/рода.

### 5.2 Тяжба (иск)

1. Род подаёт **иск** (челобитную) императору или Совету.
2. Собираются **доказательства**: грамоты, свидетели, подарки, поддержка фракций.
3. **Решение**: император/Совет голосует (учёт милости, фракций, взяток, подозрения, баланса сил): присуждение, отказ, компромисс (раздел, выкуп), отсрочка.
4. Последствия: переход прав, мнение сторон, возможная обида; отказ может подтолкнуть к интригам.

Цена иска: деньги (судебные издержки, подарки), время (3–12 мес.), милость. **Иски и тяжбы (решено) вводятся в M2 вместе с Советом** (E34, GDD 02 §6.4); в M1 споры решаются интригами и событиями.

### 5.3 Захват без права

Захват земли или должности без решения — **преступление** (самоуправство): расследование, штраф, опала. Возможен только в гражданской войне (фаза 4) в рамках блоков.

## 6. Дипломатические действия

| Действие | Описание | Цена |
|---|---|---|
| **Подарок** | Деньги, товары, землю (редко) → мнение + | Деньги |
| **Просить услугу** | Запрос поддержки/голоса/кредита | Милость, мнение |
| **Предложить брак** | GDD 01 §7 | Приданое, честь |
| **Предложить договор** | Выбор типа, условий | Переговоры (время) |
| **Потребовать** | Давление (долг, обещание) | Риск обиды, `trust` |
| **Донос/осуждение** | Публичное осуждение рода | Риск обиды, `suspicion` (GDD 04) |
| **Примирение/мировая** | Урегулирование обиды | Деньги, уступки |
| **Посредничество** | Мирит двух других родов | Милость, честь |
| **Пригласить в блок** | В кризисе (GDD 02) | — |
| **Внести залог** | Залог мира (денежный) | Деньги/права на срок |

Каждое действие — **команда** (ADR-0001); стоимость и кулдаун в данных; ИИ использует те же команды.

## 7. Обиды, вражда и примирение

- **Обида (`grudge`)** возникает от оскорблений, нарушенных обещаний, убийств, лишения должностей, отказа в браке; имеет `severity`, срок затухания (годы), список эскалаций.
- **Вражда (`feud`)** — состояние при `grudge` выше порога: бонусы к враждебным схемам (GDD 04), отказ от договоров, злорадство при несчастье.
- **Примирение:** мировая (условия: вира — денежная компенсация, брачный союз, извинение, уступка, посредничество императора/Церкви); срок и повтор нарушения.
- **Месть по наследству:** обида переходит к наследнику с затуханием.
- ИИ отыгрывает вражду с гистерезисом, чтобы не мстить каждую неделю.

## 8. Архитектура ИИ

### 8.1 Принципы

1. **Один интерфейс** для всех ИИ-акторов: `perceive → deliberate → act`.
2. ИИ читает **снапшот** и выдаёт **команды** (ADR-0001), не меняет мир напрямую; команды проходят те же проверки, что у игрока.
3. **Только доступное знание**: ИИ видит то, что видел бы род (общая функция видимости для UI и ИИ — один источник правды).
4. **Детерминизм**: решения зависят от снапшота, PRNG рода (отдельный поток) и фиксированного порядка обработки.
5. **Бюджет** измеряется в **единицах работы**, а не в миллисекундах (иначе результат зависит от скорости машины).
6. **Объяснимость**: каждое решение пишет причину в кольцевой журнал.

### 8.2 Интерфейс агента (набросок)

```cpp
struct AiAgent {
    virtual void perceive(const WorldView& view, Knowledge& k) = 0;    // обновить знания
    virtual void deliberate(const Knowledge& k, Rng& rng, Budget& b,
                            GoalSet& goals) = 0;                        // выбрать цели
    virtual void act(const GoalSet& goals, CommandSink& out, Budget& b) = 0; // сгенерировать команды
    virtual void explain(DecisionLog& log) const = 0;
};
// Реализации: DynastyAi, EmperorAi (GDD 02), ChurchAi (GDD 05), ArmyAi (GDD 06), BlocAi (GDD 02 §8)
```

### 8.3 Личность

Архетип рода определяется чертами главы и традициями рода [предл. 8 архетипов]:

| Архетип | Склонности |
|---|---|
| **Честолюбец** | Должности, престиж, претензии, риск заговора |
| **Лоялист** | Служба императору, доносы, стабильность |
| **Стяжатель** | Доходы, земли, торговля, коррупция |
| **Благочестивец** | Церковь, браки по канону, меньше интриг |
| **Интриган** | Схемы, секреты, шантаж |
| **Хозяйственник** | Развитие, здания, избегание рисков |
| **Воитель** | Армии, слава, должности командиров |
| **Реформатор** | Новые порядки, Табель о рангах, сближение с «птенцами» |

Архетип задаёт веса целей; ситуация (кризис, голод, смерть главы) их модифицирует. Архетип может **меняться** при смене главы. Архетипы — **файлы данных** (веса целей, риск, прощение); в релизе 8, моды могут добавлять новые (решено, NFR-MOD-1).

### 8.4 Цели

Каталог целей [предл.]: получить должность X; обеспечить наследника (брак); укрепить владения (строить, снабжать); накопить деньги; повысить милость; ослабить соперника; защититься от расследования; сблизиться с фракцией; выбрать веру/позицию (GDD 05); поддержать/подорвать императора; подготовить претензию/переворот; пережить кризис.

Оценка цели: `utility = need × opportunity × archetype_weight − cost`, с **гистерезисом** (текущая цель получает бонус удержания) и **обязательствами** (начатое доводится, если не утратило смысл).

### 8.5 Планировщики

Для выбранных целей модули-**планировщики** (простые эвристики, а не поиск по дереву) генерируют кандидатов команд:
- *Дворовый* (GDD 04): кандидатуры на должности, схемы, подарки;
- *Династический* (GDD 01): браки, образование, наследники;
- *Экономический* (GDD 03): строительство, политики, найм;
- *Дипломатический* (§4–6): договоры, мировые, иски;
- *Религиозный* (GDD 05): позиция, пожертвования;
- *Военный* (GDD 06): набор, назначение командиров;
- *Кризисный* (GDD 02): позиция, участие в заговоре.

### 8.6 Бюджет внимания

У каждого рода есть **очки внимания (AP)** в месяц [предл. 6–20 по размеру двора и навыкам главы]. Каждая команда стоит AP; AP не накапливаются сверх 2×. Это ограничивает «APM» ИИ, делает поведение правдоподобным и снижает нагрузку.

### 8.7 LOD и расписание

| Тир | Кто | Периодичность | Глубина |
|---|---|---|---|
| **1** | Игрок, ≤ ~10 родов вокруг престола и в активном кризисе, партнёры по договорам с игроком | Еженедельно | Полные планировщики |
| **2** | ≤ ~30 родов средней важности | Ежемесячно | Урезанные планировщики |
| **3** | Остальные | Ежеквартально | Эвристики «фонового дрейфа» (браки, смерти, упрощённые изменения) |

Динамическое **повышение тира** при событиях (кризис, претензия, смерть главы, связь с игроком). Расписание — детерминированная очередь `(due_date, dynasty_id)`.

### 8.8 Бюджет работы и разделение по тикам

- На тик — квота **единиц работы** (WU): оценка сложности (сколько кандидатов оценено, сколько отношений просмотрено).
- Незавершённые вычисления **переходят на следующий тик** без потери состояния (сохраняемая «рамка» вычисления).
- Квота рассчитывается из **целевой доли времени тика** (напр., ≤ 1 мс среднее, ≤ 3 мс пик [предл.]) и калибруется **замерами** (бенчмарки), но сама квота выражена в WU, чтобы поведение не зависело от скорости железа.
- Жёсткий предохранитель: если ИИ превысил реальный лимит времени, вызывается *отложенное* выполнение (детерминизм сохраняется, потому что квота WU, а не время, решает, что делать).

### 8.9 Память и обучение

- Журнал событий роды: кто сделал что (обиды, услуги, обещания) — в записях отношений (§3.1).
- ИИ **не обучается** в процессе партии (никакого ML), но параметры целей/личностей настраиваются данными и тестами.
- Реакция на игрока: ИИ запоминает обиды и услуги так же, как между ИИ.

### 8.10 Баланс и «снежный ком»

Механизмы против «победителя-снежного кома»:
- **Баланс сил**: сильнейшие роды вызывают подозрение императора (GDD 02 §5.4) и объединение против них (союзы ИИ, голоса Совета).
- **Лимиты** по должностям, армиям, схемам.
- **Расходы** на содержание растут с размером владений (GDD 03).
- **Усталость** фракций и обязательства по службе.

### 8.11 Честность ИИ (политика читов)

По умолчанию **без скрытых бонусов**: ИИ подчиняется тем же правилам и видимости. **Три уровня сложности (решено):** дружелюбные / реалистичные / беспощадные роды. Они меняют *явно показанные* параметры (агрессивность, «прощение» обид, точность оценок, лимиты AP, склонность к союзам против сильнейшего), а не скрывают чит-ресурсы. Уровень задаётся при старте партии и показывается в настройках.

## 9. Дипломатия с императором и Церковью

Император и Церковь — акторы того же интерфейса, но с особыми действиями:
- *Император*: назначения, жалования, ссуды, иски, опала, вызов ко двору (GDD 02, 04);
- *Церковь*: благословение, отлучение, разрешения (GDD 05).
Для игрока они появляются в окне «Отношения» отдельными записями с мнением/милостью/подозрением.

## 10. Внешний мир

Внешние державы **не акторы** (FR-DIP-4): дипломатия с ними — **события и давление на фронтах** (GDD 06 §11). Исключения для M2: события приглашения иностранных специалистов, брачные переговоры с иностранными домами (событием), посольства (событием) — без отдельных отношений и ИИ.

|---|---|
| **Отношения** | Список родов: мнение, доверие, договоры, обиды; фильтры и сортировка; быстрые действия |
| **Профиль рода** | Глава, честь, владения, вера, фракция, публичные договоры, архетип (по намекам и разведке), милость императора |
| **Конструктор договора** | Выбор типа, условий, срока; предварительная оценка согласия с причинами |
| **Входящие предложения** | Список с условиями, сроками, вариантами ответа («принять/отказать/встречное») и подсказкой последствий |
| **Тяжбы** | Мои иски, чужие иски против меня, ход, доказательства |
| **Слухи (gossip)** | Лента публичных событий между родами (договоры, браки, ссоры) |
| **Режимы карты** | Отношения к выбранному роду (цвет по мнению), договоры, вражда |

**Объяснимость в интерфейсе (решено):** игрок видит **итог** действий ИИ и **причины отказов/согласий в тултипах** (три главных фактора); намёки на мотивы даёт разведка (шпионаж, придворные). Полный журнал решений ИИ (цели, оценки) — только в режиме разработчика, чтобы не ломать «туман».

## 12. Производительность и данные

- Отношения: ≤ 100 родов × K = 40 → ≤ ~4 000 записей (≈ 100 КБ).
- Договоры: ≤ ~400 в мире [предл.].
- ИИ: бюджет по WU; средний вклад ≤ 1 мс/тик, пик ≤ 3 мс [предл.]; бенчмарки в CI с контролем регрессий (ADR-0002 P8).
- Журнал решений: кольцевой буфер на ИИ-агента (≤ 64 записи); в релизе — только минимальный.
- Данные: архетипы, веса целей, модификаторы мнения, шаблоны договоров, стоимость действий — файлы контента.

## 13. Тесты и критерии приёмки

### 13.1 AI-only симуляции (headless, `tools/`)

Прогон N seed × 50 лет без игрока, метрики с допустимыми диапазонами [предл.]:
- доля родов, вымерших за 50 лет: 5–25%;
- распределение чести: нет вырождения (доля сильнейшего рода ≤ 35% от суммы);
- число браков, договоров, мировых, исков на род в год — в «правдоподобных» диапазонах;
- частота переворотов и гражданской войны (GDD 02 §14.1);
- отсутствие «зависаний» (роды, не совершающие команд > N месяцев при ненулевой цели);
- бюджет ИИ не превышает квоту WU на тик.
Ночной CI гоняет набор seed и сравнивает с эталонными распределениями.

### 13.2 Приёмочные сценарии

- **DIP-A1.** Игрок предлагает брак роду с мнением 40 и доверием 60. Тогда: согласие/отказ с тремя главными причинами в тултипе; при отказе — встречное предложение.
- **DIP-A2.** Нарушение брачного союза пострижением жены: `trust` падает, возникает `grudge`, родня жены получает бонус к враждебным схемам.
- **DIP-A3.** Мировая между двумя враждующими родами при посредничестве Церкви: `grudge` снижается на долю, обязательство вира; повторная обида — вражда усиливается.
- **DIP-A4.** Иск на провинцию: сбор доказательств, голосование/решение императора; результат зависит от грамот, милости, взяток; отказ порождает обиду.
- **DIP-A5.** Самоуправство (захват земли без иска): расследование, штраф, возможная опала.
- **DIP-A6.** Входящее предложение игроку: отображаются условия, сроки, оценка последствий; игнорирование через N дней = отказ.
- **AI-A1.** Два прогона с одним seed → идентичная последовательность команд ИИ (хеш).
- **AI-A2.** Падение производительности (замедленная машина): поведение ИИ не меняется (квота в WU).
- **AI-A3.** Повышение тира: при смерти главы далёкого рода тир временно повышается; решения о наследстве принимаются в срок.
- **AI-A4.** ИИ не использует информацию вне видимости (тест на утечки знания: подмена скрытых данных не меняет решений).

### 13.3 Инварианты

- участники договора существуют; сроки не отрицательные;
- `opinion` −100…100; `trust`, `fear` 0…100;
- у рода не более K записей отношений и не более 8 договоров;
- команды ИИ всегда проходят валидацию (нарушения — баги, счётчик в телеметрии);
- сумма AP не превышает кап.

## 14. Границы MVP (M1)

**Входит:** отношения (мнение с разложением, доверие) для 3–4 родов, договоры: брачный союз, залог мира, простой союз; действия: подарок, предложить брак, просить услугу, предложить договор; входящие предложения; **ИИ тира 1** для 3–4 родов: 5 целей (должность, брак, деньги, милость, защита), 4 архетипа, AP, бюджет в WU, журнал решений, кольцевой лог; окно «Отношения» и «Входящие предложения»; AI-only тест (headless).

**Не входит в M1 (M2):** тяжбы и иски (нужен Совет E34), тайные договоры, мировые с вирой, посредничество, тиры 2–3, все 8 архетипов, обмен заложниками, слухи (gossip), ИИ приглашения в блоки (нужны блоки GDD 02).
