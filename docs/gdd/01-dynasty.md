# GDD 01 — Династия и персонажи

> Статус: **черновик v0.1**. Все числа помечены **[предл.]** — это стартовые значения для настройки, а не финальный баланс.
> Покрывает: FR-DYN-1…8. Связанные эпики: **E7** (персонажи и династия), **E8** (браки и наследование), **E30** (старт партии).
> Зависимости от других систем: Двор (должности), Религия (конфессия, церковное согласие на брак), Интриги (убийства, шантаж), Престол (претензии).

## 1. Назначение и роль в игре

Династия — главный «юнит» игры (столп №1). Игрок управляет **родом**, а не отдельным человеком: через главу рода он действует, а остальные члены рода — ресурс, риск и источник сюжета. Система отвечает на вопросы:

- кто в роду, на что он способен и чего хочет;
- как род продолжается (браки, дети, воспитание, смерть);
- кто наследует власть и владения;
- как репутация рода (честь) и его внутреннее единство влияют на всё остальное.

**Опыт игрока:** «Мой глава стареет, старший сын болезненный и амбициозный, младший талантлив, но сидит в опале. Выдать дочь за Голицыных ради союза — или оставить для Нарышкиных? Если глава умрёт сейчас, начнётся раздел или вспыхнет спор?»

## 2. Основные сущности

### 2.1 Персонаж

Два уровня детализации (LOD, ADR-0002 P1):

| Уровень | Кто | Что хранится/считается | Лимит |
|---|---|---|---|
| **A — полный** | Члены игровых и ИИ-династий, носители должностей, супруги, значимые лица двора | Всё из таблицы ниже, ежегодная и событийная симуляция | ≤ ~5 000 живых (общий) |
| **B — упрощённый** | Слуги, управляющие, офицеры без родовых связей | Роль, 1–2 навыка, лояльность, жалованье, возраст; без браков и детей | ≤ ~10 000 [предл.] |
| **C — архив** | Умершие и неактуальные | Имя, годы жизни, родители, дети, род, причина смерти, ключевые факты | не ограничен, хранится компактно |

**Поля персонажа уровня A:**

| Группа | Поле | Тип | Примечание |
|---|---|---|---|
| Идентичность | `id` | `CharacterId` (u32 + поколение) | |
| | имя, отчество (производное от отца), пол | строка (интерн.), enum | Фамилия берётся у рода |
| | `birth_date`, `death_date?` | `Date` | |
| | `dynasty`, `branch` | `DynastyId`, `BranchId` | Ветвь — подрод внутри рода |
| | `portrait_id` | `u32` | Из пула, по ID (FR-UI-8) |
| Родство | `father`, `mother`, `spouses[]`, `ex_spouses[]` | `CharacterId` | Дети — производный индекс |
| | `legitimacy` | enum | законный / внебрачный / узаконенный |
| Навыки | `skills[5]` | `Fixed` 0…20 | **Хозяйство, Дипломатия, Воинское дело, Интриги, Учёность** |
| Состояние | `health` | `Fixed` 0…100 | |
| | `fertility` | `Fixed` 0…100 | Производное от возраста, здоровья, черт |
| | `stress` | `Fixed` 0…100 | Накапливается; пороги → срывы, болезни [предл.] |
| | `piety` | `Fixed` 0…100 | Личное благочестие (GDD 05 §8); влияет на отношения с духовенством, основание Церкви |
| Личность | `traits` | битовая маска ≤ 8 активных | Врождённые, приобретённые, образовательные |
| | `ambition`, `loyalty_to_head`, `loyalty_to_emperor` | `Fixed` −100…100 | Определяют поведение вне прямого контроля |
| Вера | `faith_stance` | ссылка на систему Религии | Позиция рода + личная |
| Социальное | `opinions` | разреженная карта `CharacterId → Fixed` | Только значимые связи (≤ 30 на персонажа) |
| | `rank`, `office?` | | Двор/Табель о рангах |
| | `education` | `{focus, tutor?, level}` | |
| Политика | `claims[]` | | Претензии на земли/престол |

**Имена и отчества:** отчество строится автоматически (`Иван Петрович Меншиков`); женские формы (`Анна Петровна Меншикова`) подставляются по полу. Это входит в локализацию.

### 2.2 Династия (род)

| Поле | Описание |
|---|---|
| `id`, `name`, `colors`, `coat_of_arms` | Идентичность, герб из конструктора/набора |
| `head` | Текущий глава рода |
| `branches[]` | Ветви; у каждой свой старший |
| `members` | Индекс живых персонажей уровня A |
| `honor` (честь) | `Fixed` −1000…+10000 — репутация рода |
| `unity` (единство) | `Fixed` 0…100 — сплочённость рода |
| `succession_law` | Закон наследования (см. 6) |
| `religious_stance` | Позиция по отношению к Церкви (FR-REL-2) |
| `relations` | Разреженные отношения с другими родами |
| `holdings` | Ссылки на владения (экономика) |
| `chronicle` | Летопись: список ключевых событий для итогового экрана |

**Правило игрока:** игрок видит и ведёт весь род, но в каждый момент «действует» через **главу**. Смерть главы → переход на наследника по закону (см. 6). Если наследников нет — ближайший по линии; если живых членов рода нет вообще — **поражение (FR-DYN-8)**.

## 3. Жизненный цикл

Время в игре идёт днями (FR-TIME-1). Демографические события считаются **не каждый день**, а по расписанию (ADR-0002 P2):

- **Старение и смертность** — раз в год, в день рождения персонажа (естественное распределение по дням, нагрузка сглаживается само).
- **Беременность/роды** — помесячно для замужних женщин фертильного возраста; роды по таймеру 9 месяцев.
- **Здоровье, болезни, стресс** — помесячно.
- **Образование** — помесячный прогресс, итог в день совершеннолетия.

### 3.1 Возрастные периоды [предл.]

| Возраст | Период | Особенности |
|---|---|---|
| 0–6 | Младенчество/детство | Высокая смертность, нет навыков, нет действий |
| 7–15 | Отрочество | Образование, возможны помолвки |
| 16+ | Совершеннолетие | Может занимать должности, жениться (муж. ≥ 16, жен. ≥ 15) |
| 16–50 | Расцвет | Максимум фертильности и здоровья |
| 51–65 | Зрелость | Рост риска болезней, спад фертильности |
| 66+ | Старость | Быстрое падение здоровья, повышенная смертность |

### 3.2 Смертность

Ежегодная вероятность смерти — таблица по возрастным корзинам, модифицируется здоровьем и чертами. Значения в промилле (целые), чтобы расчёт был детерминированным:

| Возраст | Базовая годовая смертность, ‰ [предл.] |
|---|---|
| 0 (первый год) | 220 |
| 1–4 | 70 |
| 5–14 | 20 |
| 15–29 | 15 |
| 30–44 | 22 |
| 45–59 | 45 |
| 60–69 | 110 |
| 70–79 | 240 |
| 80+ | 450 |

Знать живёт в среднем лучше простолюдинов — для полных персонажей применяется множитель ×0.8 к детским корзинам [предл.]; здоровье < 30 удваивает вероятность, ≥ 80 снижает её на 25%.

**Причины смерти** (для летописи и тултипов): старость, болезнь, роды, война, казнь, убийство, несчастный случай, раны, горе. Причина выбирается по контексту: смерть на войне — только при участии в армии; от родов — только у рожениц.

Болезни: набор «событий здоровья» (оспа, горячка, чахотка, цинга, «огневица» и т.д.), даёт временные штрафы и повышает шанс смерти; эпидемии — события уровня провинции, влияющие на персонажей в ней.

### 3.3 Рождение

Помесячный шанс зачатия для пары, где жена фертильна:

```
P_month = base_conception × age_factor(жена) × health_factor × trait_factor × (супруги вместе ? 1 : 0)
base_conception ≈ 12 ‰ в месяц  [предл.]   // ~ 1 роды в 1.5–2 года при расцвете
age_factor: 15–19: 0.8; 20–29: 1.0; 30–34: 0.8; 35–39: 0.5; 40–44: 0.2; 45+: 0.0
```

- Пол ребёнка: 105 мальчиков на 100 девочек [предл.].
- Риск родов для матери: 3–6% на роды, ниже при высоком здоровье и «лекаре» при дворе.
- Выкидыши, мертворождения — включены в расчёт младенческой смертности.
- Внебрачные дети: возможны как последствие событий/интриг (связь с FR-INT); получают статус «внебрачный», можно узаконить.
- **Максимальная фертильность:** жёсткий потолок ~14 детей на женщину.

### 3.4 Наследование черт и навыков

- Навык ребёнка при рождении = `0.3 × среднее родителей + случайный разброс ±3 + образование`; итоговое значение складывается к 16 годам.
- Врождённые черты: каждая имеет вероятность наследования от родителей (например, сильная 40%, слабая 10%); редкие генетические черты («гений», «слабоумный», «болезненный») — отдельные вероятности. Максимум 3 врождённых.
- Стресс и события формируют приобретённые черты в течение жизни (получил рану — «хромой», пережил осаду — «закалённый»).

## 4. Черты (traits)

Черта — именованный набор модификаторов и поведенческих «подсказок» для ИИ. Хранится в данных (FR-DATA-1), не в коде.

**Категории [предл.]:** врождённые, образовательные, характер (добродетели/пороки), жизненные (приобретённые), религиозные, здоровье.

**Пример данных (псевдоформат; финальный формат — по результатам E4):**

```
trait "ambitious" {
    category = personality
    opposite = "content"
    skills = { diplomacy = +1, intrigue = +2 }
    modifiers = { ambition = +30, opinion_of_superiors = -10 }
    ai_hint = { seeks_promotion = +2, joins_plots = +1 }
    inherit_chance = 0.15
    name = "trait.ambitious.name"
    desc = "trait.ambitious.desc"
}
```

**Стартовый набор для MVP (≈ 25 черт):**
- характер: честолюбивый, осторожный, жестокий, милосердный, щедрый, скупой, набожный, вольнодумец, гордый, ленивый;
- образование: учёный, воин, хозяйственник, придворный, дипломат, интриган;
- здоровье/судьба: болезненный, крепкий, хромой, красавец, слабоумный;
- жизненные: герой войны, опальный, любимец императора, вдовец/вдова и т.д.

**Правила черт:**
- не более 8 активных; противоположности взаимоисключающие;
- каждая черта влияет на навыки, отношения (мнение), шансы событий и поведение ИИ;
- тултип персонажа показывает вклад каждой черты в итоговые значения (FR-UI-3).

## 5. Образование

- В 6–7 лет глава рода (или регент) выбирает **направление образования**: хозяйственное, дипломатическое, воинское, придворное/интриги, учёное; можно назначить **наставника** (из двора, платного, священнослужителя).
- Результат определяется навыками наставника, способностями ребёнка, стоимостью и временем; в 16 лет ребёнок получает образовательную черту и бонусы навыков.
- Зарубежное обучение (в сеттинге Петра — стандартная практика «в науку за границу») — дорогой вариант: больше навыков, шанс «вольнодумства» и расхождения с традиционалистами.
- Для упрощённой версии (MVP): выбор направления + наставник по желанию, без отдельных учебных событий.

## 6. Наследование

Закон наследования — свойство рода (и, отдельно, владений/должностей, если появится разница). Меняется **реформой** (стоит чести, единства и казны; может вызвать недовольство).

| Закон | Правило | Плюсы | Минусы |
|---|---|---|---|
| **Майорат** | Всё старшему сыну (прямая линия, мужчины в приоритете) | Целостность владений | Младшие обделены → мятежные |
| **Минорат** | Всё младшему сыну | Редкий, традиционный в некоторых землях | Старшие недовольны |
| **Раздел** | Владения делятся между сыновьями (удельный раздел) | Все довольны, нет изгоев | Дробление, ослабление рода |
| **Семейный совет** | Выбор главы голосованием членов рода (авторитет, честь, связи) | Сильнейший претендент | Возможен спор, склоки |
| **Назначение главой** | Глава называет преемника (в духе указа Петра о престолонаследии 1722 г. — как исторический якорь) | Гибкость | Риск: не успел назначить — хаос |

**Порядок при отсутствии наследника по закону:** сыновья → дочери и их дети (если закон допускает) → братья → племянники → ближайший по родству член рода по совету.

**Спор о наследстве** запускается, когда:
- есть несколько законных претендентов с близкой силой;
- наследник по закону непопулярен (low loyalty + low opinion);
- глава умер без назначения при законе «назначение».

Спор порождает **кризис рода**: рост `unity`-штрафов, возможность восстания ветвей, вмешательство императора и других родов (связь с Интригами/Престолом).

Престол империи наследуется по **своим правилам** (отдельный объект «закон престолонаследия» в системе Престола); данный GDD описывает наследование внутри рода.

### 6.2 Женщины в роду

- **Глава рода:** женщина становится главой, только если в роду нет живых совершеннолетних мужчин **или** предыдущий глава назначил её (закон «назначение»). Такая глава имеет штраф к чести и повышенный риск оспаривания (мужчины других ветвей и родов могут выдвигать претензии).
- **Должности:** доступен ограниченный набор — придворные женские должности (статс-дама, управительница двора и т.п.), настоятельница монастыря, регентство. Военные и приказные должности недоступны.
- **Влияние:** через браки, дворцовое окружение, ведение хозяйства имения мужа (управление владением в отсутствие мужа), патронаж, интриги. Женщины — полноценные участницы схем (подкуп, шпионаж, сватовство, отравление).
- **Владения:** женщина может владеть приданым и вдовьей долей; прямое владение провинциями — только вдовы и главы-женщины.

### 6.3 Регентство

Если наследник младше 16 лет (совершеннолетие), назначается **регент** — управляет родом и владениями до его совершеннолетия.

**Кандидаты в регенты (по приоритету, меняется законом/завещанием):** мать (вдова), назначенный завещанием, старший дядя, семейный совет, император.

**Правила:**
- Регент действует как глава рода (все команды игрока идут через него), но его лояльность к наследнику — отдельный параметр.
- Каждый год регентства проверяется риск **узурпации**: `risk ∝ амбиции регента × (100 − лояльность к наследнику) × слабость наследника`. При срабатывании регент может: захватить главенство, устранить наследника (интриги), заключить выгодные себе браки.
- Если игрок ведёт малолетнего наследника, он может **противодействовать** (искать союзников, смещать регента через семейный совет или императора, устроить побег наследника).
- Контроль императора: император вправе назначить опекуна рода, если род слаб или в смуте.
- Малолетний наследник приобретает черты по влиянию регента (воспитание).
- Для M1 достаточно: автоматическое назначение регента + проверка узурпации + событие смещения.

### 6.4 Фавориты

**Фаворит** — должность двора (не отдельная механика родства): назначается императором или главой рода из числа придворных, даёт доступ к «уху» власти, влияет на милость, назначения, интриги. Любовная связь не обязательна — это политическая роль (как у Меншикова при Петре). Подробности — в GDD «Двор»; из этого GDD ссылки: фаворит рода может быть источником мнения, патронажа и скандалов (связь с FR-COURT-4 и событиями).

## 7. Браки

### 7.1 Типы браков

| Тип | Кто решает | Особенности |
|---|---|---|
| Договорной (династический) | Глава рода/родители | Основной в игре; приданое, союз, залог мира |
| По склонности | Сам персонаж (по событию/черте) | Может противоречить интересам рода → конфликт |
| Принудительный | Император, глава рода | Вознаграждение или опала; недовольство |
| Брак с иноверцем/иностранцем | Требует согласия Церкви и/или смены веры | См. Религию |

### 7.2 Поиск партии

Пул кандидатов формируется из доступных персонажей: возраст, пол, свободны, не в запретной степени родства, подходящее сословие. Для каждого кандидата UI показывает **оценку партии**: честь рода, приданое, связи, здоровье, фертильность, навыки, конфессия.

**Вероятность согласия стороны** (для ИИ и для ответа игроку):

```
accept_score = w1 × честь_жениха_рода_отн + w2 × приданое + w3 × политич_выгода
             + w4 × мнение_о_инициаторе − w5 × разница_в_ранге − штраф_за_конфессию
```

Если `accept_score ≥ порог` — согласие; иначе отказ с причиной (тултип). Отказы влияют на мнение.

### 7.3 Правила и ограничения

Правила **реалистичные** (решено): церковные ограничения действуют в полном объёме, но имеют механизмы обхода за цену. Точные степени и нормы уточняются по источникам на этапе спецификации данных.

- **Родство по крови и свойству:** запрет браков в широкой степени (в каноне Русской церкви — до 6–7-й степени; точные значения — **[проверить по источникам]**, в игре параметр `forbidden_degree` на конфессию). Исключения возможны по **разрешению Церкви** (цена: честь, взнос, милость иерархов, влияние фракций).
- **Духовное родство:** крёстный и крестник, крёстные родители, восприемники в браках связаны духовным родством — браки между ними запрещены. Одновременно крёстные — **политическая связь** (союз, патронаж): при рождении ребёнка игрок выбирает крёстных (M2 по умолчанию, в M1 — автоматически).
- **Согласие Церкви и венчание:** брак без согласия священника/епископа считается недействительным; незаконный брак — штраф чести, дети с низшим статусом.
- **Число браков:** допустимо до трёх; четвёртый — запрещён; третий брак ухудшает мнение Церкви и сопровождается епитимьей (штраф чести).
- **Разный вероисповедный статус:** брак православного с иноверцем без перехода в веру недействителен (для иноверных супругов — событие смены веры; последствия для их рода).
- **Минимальный возраст:** жен. ≥ 15, муж. ≥ 16 (до церковного совершеннолетия — только помолвка).
- **Развод** в современном виде отсутствует; вместо него — **пострижение супруги/супруга** (исторический способ расторжения брака: пример — царица Евдокия, 1698). Действие: супруга в монастырь, брак расторгнут, штраф к чести, возможная обида рода жены; политические последствия.
- **Вдовство:** срок траура, затем повторный брак; вдовы владеют частью имущества (приданое).
- **Иноверческий брак:** требует перехода в веру или разрешения; отдельная ветка событий (см. GDD «Религия»).

### 7.4 Договорные браки между родами

Могут входить в **договоры** (союз, залог мира, раздел претензий). Нарушение договора (развод, пострижение жены) → штрафы к мнению и чести. Дочери и сёстры — важный ресурс политики.

### 7.5 Приданое

Деньги, земли или права; размер зависит от чести и состояния рода. Передаётся при браке, возвращается частично при пострижении/расторжении (по договору). Вдова сохраняет приданое.

## 8. Честь (honor) и единство (unity) рода

### 8.1 Честь

Репутация и вес рода в обществе. Влияет на браки, отношение сословий, шанс получить должность, поддержку фракций, претензии на престол.

**Источники (+)**: высокие должности членов рода, победы, браки со знатными, рождение наследников, милость императора, щедрость, благотворительность, постройка церквей.
**Потери (−)**: измена, раскрытый заговор, казнь или опала члена рода, позорный брак, поражения, невыплата долгов, пострижение жены (по обстоятельствам).

Честь дискретизируется в **ранги рода** (например, «захудалый», «служилый», «знатный», «великий», «первейший») с порогами, влияющими на доступные браки и должности.

### 8.2 Единство

Показатель сплочённости рода (0–100): высокое — члены рода слушаются главу и помогают друг другу; низкое — ветви интригуют, отказываются выполнять поручения, участвуют в заговорах против главы.

**Влияет на:** лояльность (`loyalty_to_head` каждого), шанс отказов на поручения, риск внутреннего заговора, силу голосований в семейном совете.

**Изменяется:** повышается — общими победами, совместными браками, щедрой раздачей; падает — спором о наследстве, фаворитизмом, обидами, нарушением традиций, неравным разделом.

## 9. Управление родом (что делает игрок)

Игрок действует через **команды**; все команды — также команды для ИИ (ADR-0001).

| Команда | Описание | Ограничения |
|---|---|---|
| `AssignOffice(c, office)` | Назначить на должность (через Двор) | Требования должности |
| `ArrangeMarriage(a, b, terms)` | Предложить брак | Кандидаты подходят, согласие |
| `Betroth(a, b)` | Помолвка (дети) | Возрастные ограничения |
| `Tonsure(c)` | Пострижение | Последствия для чести |
| `SetEducation(child, focus, tutor?)` | Образование | |
| `SetHeir(c)` | Назначить преемника | Закон допускает |
| `ChangeSuccessionLaw(law)` | Реформа | Цена, срок, недовольство |
| `GrantLand(c, province)` | Выделить владение члену рода | Сокращает собственное, повышает лояльность |
| `Disown(c)` | Отлучение/лишение прав | Штраф к единству |
| `OrderMember(c, task)` | Поручить дело (интрига, посольство, армия) | Член может отказаться при низкой лояльности |

Члены рода, помимо приказов, действуют **по собственной воле** (ИИ членов рода): ищут должности, женятся по склонности, участвуют в заговорах, ссорятся. Игрок видит это в виде событий и уведомлений с вариантами реакции.

## 10. Интерфейс

Окна (на базе RmlUi, FR-UI-2):

1. **Древо рода** — граф «родители–дети–браки», фильтры (живые/все, ветвь), клик → окно персонажа. Для больших родов — сворачивание ветвей.
2. **Окно персонажа** — портрет, имя/отчество/возраст, навыки с разложением, черты, здоровье, семья, должность, претензии, мнения, действия.
3. **Совет рода** — список членов с лояльностью/амбициями, закон наследования, показатели единства и чести, список претендентов, кнопка реформы.
4. **Поиск партии** — список кандидатов с оценкой, фильтры, переговоры.
5. **Журнал/летопись** — события рода по датам.

**Тултипы:** каждая цифра (навык, шанс, лояльность) раскрывается в слагаемые. Это требование проекта (FR-UI-3), поэтому формулы должны возвращать **разложение** результата, а не только число.

## 11. События (примеры)

Все — данные, не код (FR-EVT-3). Триггеры подписываются на изменения персонажей (ADR-0002 P5).

- Рождение наследника / мертворождение / смерть при родах.
- Болезнь главы: варианты лечения (лекарь, обет, паломничество).
- Старший сын требует удел.
- Дочь влюбилась в человека не вашего круга.
- Дядя оспаривает права внука на наследство.
- Возвращение из-за границы: «новые взгляды» (Пётровская эпоха) — спор отцов и детей.
- Пострижение жены: реакция её рода.
- Внебрачный ребёнок обнаружен — признать/скрыть/отдать в монастырь.
- Смерть главы: церемония, споры о наследстве, призыв императора.

Для MVP достаточно ~20 событий этого блока.

## 12. Производительность и данные

- Все персонажи в SoA-массивах по полям (кэш-дружелюбно, ADR-0002 P4).
- Ежегодные расчёты **размазаны** по дням: персонаж обрабатывается в день рождения; месячные — по `id % 30`.
- Мнения хранятся разреженно, лимит 30 на персонажа; старые затухают и удаляются.
- При смерти персонаж переводится в **архив (C)**: освобождаются навыки, мнения, черты; остаются родство и факты для древа и летописи.
- Далёкие от игрока персонажи (чужие рода вне круга интереса) считаются реже/упрощённо (LOD по расстоянию влияния).
- Бюджет: годовая демографическая обработка 5 000 персонажей ≤ 5 мс суммарно на день-пиковую нагрузку; помесячный обход фертильных пар ≤ 2 мс [предл.].
- Сейв: персонажи сериализуются плотно; архив — в сжатый блок.

## 13. Тесты и критерии приёмки

### 13.1 Демографические тесты (автоматические)

Прогон мира 100 лет без игрока (seed фиксирован), проверка метрик в допусках [предл.]:

- ожидаемая продолжительность жизни знати при рождении: 38–48 лет;
- средняя «завершённая» рождаемость у замужних женщин знати: 5–8 детей на женщину;
- доля мальчиков при рождении: 51–52%;
- вымирание рода при начальной численности 12 человек за 100 лет — не более X% родов (калибровка);
- рост числа живых персонажей ограничен и выходит на плато (нет экспоненты).

### 13.2 Приёмочные сценарии

- **DYN-A1.** *Дано:* род с главой 45 лет, женой 30 лет и тремя детьми. *Когда:* прошло 5 лет без вмешательства. *Тогда:* в роду родилось 1–4 ребёнка (в большинстве прогонов); возраст всех увеличился; нет нарушений инвариантов (родство симметрично, нет живых с `death_date`).
- **DYN-A2.** *Дано:* закон «майорат», глава умер, есть старший сын 17 лет. *Тогда:* он становится главой, `unity` меняется по правилам, в летописи запись.
- **DYN-A3.** *Дано:* закон «семейный совет», два претендента с близкими очками. *Тогда:* запускается спор; результат зависит от голосов; `unity` падает.
- **DYN-A4.** *Дано:* предложение брака с недопустимой степенью родства. *Тогда:* команда отклоняется с понятной причиной в тултипе.
- **DYN-A5.** Пострижение жены: брак расторгнут, честь падает, род жены получает негативное мнение, приданое возвращается по условиям договора.
- **DYN-A6.** Вымирание: умирает последний член рода → игра заканчивается экраном поражения и летописью.
- **DYN-A7.** Детерминизм: два прогона с одним seed и потоком команд дают одинаковый хеш состояния династий.

### 13.3 Инварианты (проверяются property-тестами)

- у каждого живого персонажа дата рождения не позже текущей даты; в родстве нет циклов;
- у ребёнка максимум два родителя; супруг симметричен;
- сумма персонажей по родам = общему числу живых уровня A;
- `unity`, `honor`, `health` — в допустимых границах;
- смерть удаляет персонажа из всех индексов (должности, армии, схемы) или корректно их переназначает.

## 14. Границы MVP (M1)

**Входит:** персонаж уровня A и архив (уровень B — только заглушка для слуг), 5 навыков, ~25 черт, здоровье, смертность и рождение по таблицам, образование (выбор направления), браки (договорные, простое согласие), пострижение, законы наследования: майорат, раздел, назначение; честь и единство в базовом виде; древо рода, окно персонажа, поиск партии, летопись; ~20 событий.

**Не входит в M1:** семейный совет как голосование (только в M2), болезни как отдельные эпидемии, зарубежное обучение, сложные договоры с приданым, сложная генетика черт, ИИ-поведение членов рода сверх базового.
