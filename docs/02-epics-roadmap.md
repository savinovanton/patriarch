# Эпики и дорожная карта

> Статус: **черновик v0.1**. Размеры — T-shirt (S ≤ 1 нед., M 2–4 нед., L 1–2 мес., XL 2+ мес.) для соло-разработки. Это грубая оценка, а не обещание сроков.
> Каждый эпик ссылается на требования из `01-tz.md`. Задачи (stories) будем раскладывать эпик за эпиком.

## Порядок и вехи

```
M0  Фундамент и спайки        ──►  решение по UI-стеку, измеренный прототип ядра
M1  Вертикальный срез (MVP)   ──►  играбельный мини-мир: 20 провинций, 3–4 династии
M2  Альфа                     ──►  все системы в базовом виде на полной карте
M3  Бета                      ──►  контент, баланс, оптимизация, локализация
M4  Релиз                     ──►  полировка, Steam-пакет
```

## Как раскладывать эпик на задачи

Для каждого эпика будем делать отдельный файл `docs/epics/EXX-name.md`:

1. **Цель и ссылки** на требования ТЗ.
2. **Спецификация** (поведение, формулы, граничные случаи, UI-макет).
3. **User stories** + критерии приёмки (Given/When/Then).
4. **Технические задачи** (с оценкой S/M/L) и зависимости.
5. **Тесты и бенчмарки** (что должно быть измерено).
6. **Риски и открытые вопросы**.

## Предлагаемый порядок работы над документацией

1. Закрыть открытые вопросы из `03-open-questions.md`.
2. Детальные спецификации по системам (GDD): Династия → Владения → Двор → Престол → Интриги → Армия → Дипломатия → События.
3. Эпики M0 → задачи (готовы к старту разработки).
4. Эпики M1 → задачи.
