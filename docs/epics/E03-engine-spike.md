# E3 — Спайк движка: Direct3D 11 + RmlUi

> Веха: **M0**. Размер: **L (~29 дней полным объёмом; ~23 дня «рисковый минимум» по таблице; ~14 дней сокращённый вариант)**. Статус: **готов к старту после E0-T05**.
> Опирается на: ADR-0001 (D3D11, SDL3, RmlUi, критерии спайка), TZ FR-UI-1…8, NFR-PERF-1, GDD 03 (карта, режимы), GDD 08 (окно события, тултипы).
> Оценки: **S** ≤ 1 дн., **M** 2–3 дн., **L** ~1 нед., **XL** > 1 нед.

## 1. Цель

Доказать за ограниченное время (time-box) три вещи из ADR-0001, прежде чем строить на них игру:

1. **Карта:** индексная текстура ~400 провинций, смена режима карты палитрой, зум/пан, выбор провинции — **60+ FPS**.
2. **UI:** окно «персонаж» на RmlUi: кириллица, **вложенные тултипы**, список на 1 000 строк со скроллом, привязка данных к снапшоту.
3. **Связка с ядром:** карта и окно показывают данные из потока симуляции (E1) без блокировок.

Если RmlUi не проходит, фиксируем запасной план (ADR-0001, п. 5): Dear ImGui для инструментов + свой лёгкий игровой UI.

## 2. Объём

**Входит:** окно/ввод, рендерер D3D11, пайплайн карты (процедурная тестовая карта), рендер карты, интеграция RmlUi, прототип окна «персонаж», вложенные тултипы, базовая тема «старинная карта», замеры, итоговое решение.
**Не входит:** игровые окна кроме прототипа, финальная карта России (E21), арт (E26), звук.

## 3. Time-box и режим «рисковый минимум»

Эпик можно проходить тремя уровнями:

- **Сокращённый (~14 дней):** те же задачи, но упрощённо — карта без шейдера границ (границы линиями из T03), окно «персонаж» без вкладок, тултипы глубиной в один уровень + заглушка вложенности. Отвечает на вопрос «стек в принципе жив».
- **Рисковый минимум (~23 дня, колонка «Минимум»):** T01, T02, T03, T04, T06, T07, T08, T10, T11 в полном виде. Решение по ADR-0001 принимается здесь.
- **Полный объём (~29 дней):** добавляются T05 (подписи на карте), T09 (тема), T12 (связка с ядром E1).

Рекомендация: пройти сокращённый уровень, принять предварительное решение, затем добить недостающее по ходу M1, а не растягивать спайк.

## 4. Пользовательские истории и критерии приёмки

**US-3.1.** *Как игрок, я хочу плавную карту.*
- *Дано:* тестовая карта 400 провинций, разрешение 1920×1080. *Когда:* зум, пан и смена режима карты 10 раз подряд. *Тогда:* кадр ≤ 16.6 мс (p95), смена режима ≤ 2 мс CPU, без пересоздания геометрии.

**US-3.2.** *Как игрок, я хочу выбирать провинцию кликом.*
- *Дано:* курсор над провинцией. *Когда:* клик. *Тогда:* выбирается корректная провинция (по ID под курсором, включая границы и малые провинции); подсветка и рамка отображаются.

**US-3.3.** *Как игрок, я хочу понятные тултипы.*
- *Дано:* окно «персонаж» с навыком «Хозяйство 9». *Когда:* навожу курсор на значение. *Тогда:* появляется тултип с разложением («Базовое +4, Образование +3, Черта “Хозяйственник” +2»), внутри можно навести курсор на слагаемое и получить второй тултип.

**US-3.4.** *Как игрок, я хочу читать русский текст.*
- *Дано:* текст с кириллицей, ё, ъ, кавычками «…», тире и длинными словами. *Когда:* отображение в окнах и тултипах на 100%, 125%, 150%, 200% масштаба. *Тогда:* нет «тофу», переносы корректны, текст читаем.

**US-3.5.** *Как разработчик, я хочу, чтобы UI читал данные ядра без блокировок.*
- *Дано:* симуляция работает на скорости 5. *Когда:* окно «персонаж» и карта обновляются по снапшотам. *Тогда:* кадры не пропускаются, значения согласованы.

## 6. Тесты и проверки

- Автоматические: сборка шейдеров, загрузка карты (хеш), unit-тесты тултипного движка (позиционирование, вложенность).
- Скриншот-тесты (опционально): эталонные кадры окна «персонаж» на масштабах 100/150/200%.
- Ручной чек-лист: кириллица, масштаб, мониторы с разным DPI, перемещение окна между мониторами.
- Замеры производительности по пресетам из E2-T08 («слабый профиль»).

## 7. Риски и вопросы

| Риск | Митигация |
|---|---|
| RmlUi не подходит (клип-маски, производительность списков, тултипы) | Критерии провала записаны заранее; запасной план: ImGui для инструментов + свой лёгкий слой |
| D3D11 render interface для RmlUi требует больше времени | Использовать референсные бэкенды RmlUi как образец; ограничить функции (без сложных фильтров) |
| Кириллица и шрифты (лицензии, метрики) | Выбрать 2 шрифта с открытой лицензией (серифный текст + заголовочный), проверка наборов глифов на ё/ъ и типографике |
| Спайк «разрастается» в игру | Жёсткий time-box; по завершении — только решение и переход к M1 |

**Открытые вопросы:**
1. Какой уровень проходим: **сокращённый (~14 дней)** или **рисковый минимум (~23 дня)**? Рекомендую сокращённый, затем предварительное решение.
2. Есть ли у вас слабая машина/встроенная графика для замеров? Если нет — оцениваем по ограничениям рендера (разрешение, MSAA off).
3. Какие шрифты предпочитаете (стилистика: гражданский шрифт Петровской эпохи, классическая антиква)? Нужна проверка лицензий.
