# Дизайн интерфейса «Olive Stone» (World UI)

> Источник: макет владельца в Figma — [Patriarch Sovereign — World UI · Olive Stone](https://www.figma.com/design/XDiyizWZcVXGbpV5b2FlL7). Версия макета: «пока что такая» (2026-11-07), изменения ожидаются.
> Экран макета: **1920×1080**, кадр «World / 01 · Обзор». Заменяет прежнюю тему «старинная карта» (#19).
> Значения цветов и размеров ниже взяты из экспортированных SVG (точные); расположение блоков — со снимков макета (приблизительное, помечено [проверить]).

## 1. Идея

Тёмный оливково-каменный интерфейс поверх карты; золото — только для рамы экрана и акцентов; светлый тёплый текст. Вся карта видна в центре, панели лежат по краям и не закрывают её без нужды.

## 2. Цветовые токены (из SVG)

| Токен | Значение | Где используется |
|---|---|---|
| `panel-fill` | `#282F26` | плашки ресурсов, панели |
| `panel-stroke` | `#626D50` | рамка плашек и панелей |
| `button-fill` | `#3D4736` | кнопки левого меню |
| `button-stroke` | `#C8AF77` | рамка кнопок меню (золото) |
| `icon` | `#C5C7B5` | линии иконок (обводка 1.2–1.4 px) |
| `text-primary` | `#EEE8D8` | значения, заголовки |
| `text-secondary` | `#A0AD8B` | подписи («Казна»), приросты |
| `map-placeholder` | ≈ `#767A68` | подложка карты в макете (на глаз) [проверить] |

Фон кнопок меню светлее плашек (`#3D4736` против `#282F26`): активное и обычное состояния различаются рамкой и заливкой.

## 3. Размеры и формы

| Элемент | Размер | Заметки |
|---|---|---|
| Плашка ресурса | 144×56 | скругление ≈ 2 px, рамка 1 px, слева иконка 20×20 (центр ≈ (21, 28)), справа подпись и значение |
| Кнопка левого меню | 40×38 | скругление ≈ 2 px, рамка 1 px, иконка 24×24 по центру |
| Иконка сигнала | см. `assets/ui/olive/icons/alert_*.svg` | колокол, грамота, посольство — в верхнем правом углу |
| Рама экрана | 1920×1080 | PNG с прозрачным центром; внутренняя область ≈ от 62 px по краям [проверить] |

Шрифты в макете: подписи и значения — гротеск, заголовки — антиква с засечками (точные гарнитуры будут подтверждены; пока системные Arial / Times, #27).

## 4. Зоны экрана (кадр 1920×1080)

1. **Рама** — поверх всего, не перехватывает мышь.
2. **Левый верх** — плашка государства («Московское царство», «Государев двор») с иконкой.
3. **Верх, слева направо** — полоса ресурсов: Казна, Запасы, Войско, Вера, Влияние (значение + прирост за период).
4. **Правый верх** — три значка-сигнала (колокол, грамота, посольство) со счётчиками; ниже дата («1 сентября 1703», «Погода») и кнопки скорости (пауза, 1–5).
5. **Левый край** — вертикальное меню из 9 кнопок: Мир [1], Держава [2], Владения [3], Войско [4], Церковь [5], Хозяйство [6], Дипломатия [7], Летопись [8], Меню [Esc]. В названиях файлов макета указаны горячие клавиши.
6. **Правая панель** — «Владения» с вкладками «Города / Войска / Династии», список (Москва, Тверь, Новгород — с числами), блок «Войска» (например «Большой полк»).
7. **Правый низ под панелью** — «Дела государства»: карточки решений («Собор ожидает решения», «Прибыл посол»).
8. **Левый низ** — «Летопись»: журнал событий с временем.
9. **Правый низ** — маленькие кнопки управления картой.
10. **Центр** — карта; подписи поселений поверх неё («Москва» с иконкой).

## 5. Файлы ассетов

`assets/ui/olive/frame.png` — рама; `assets/ui/olive/icons/` — `menu_*` (9), `res_*` (5: treasury, grain, army, faith, influence), `alert_*` (3). Все записаны в `assets/LICENSES.csv` как `Original`; происхождение рамы уточняется (issue #113).

В экспорте Figma плашки ресурсов приходят с «запечённым» текстом (контуры букв) — в игре они собираются из токенов, иконки и динамического текста; исходные файлы лежат в `docs/design/olive-stone/` как справка.

## 6. Реализация

- Технический выбор для изображений: [ADR-0005](../adr/0005-ui-images.md) (PNG через WIC, SVG через RmlUi + lunasvg).
- Тема — общий RCSS с токенами; окна (`src/ui`) подключают его вместо собственных цветов.
- Порядок работ (UI-1, #112): ассеты и изображения → каркас HUD (плашка государства, ресурсы, левое меню, рама) → правая панель → «Дела государства» → «Летопись» → кнопки карты.

## 7. Состояние реализации (2026-11-07)

Готово в спайке (`apps/spike/ui/hud.rml`, `hud.rcss`, `olive.rcss`, `timebar.*`): рама, табличка государства, полоса ресурсов, значки-сигналы, левое меню (9 кнопок), панель «Владения» с вкладками «Города / Войска / Династии» и блоком «Войска», «Дела государства» (карточки), «Летопись», панель даты и скорости. Данные — заглушки (`make_test_hud`) до появления экономики и двора.

Не готово: кнопки управления картой (правый низ), подписи поселений в стиле макета, окно персонажа в теме Olive Stone, прокрутка списков, тултипы HUD. Размеры и позиции блоков измерены по снимкам макета и ждут сверки с Figma (лимит MCP).
