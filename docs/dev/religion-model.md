## 3. Типы и единицы

- Показатели Церкви, благосклонность, конфликт — `std::int32_t` ×100 (0…10 000 = 0…100 пунктов); дроби — промилле ‰, усечение к нулю после **каждого** умножения; ни `float`, ни `double`.
- Доли вер — `u16` ‰ (сумма ровно 1000); шаг динамики — `i32` в 1/1000 ‰ (µ); остаток `carry` — `i16` (|carry| < 1000).
- Деньги — копейки `i64`; в данных — `_rub`.
- Даты — `Date`; `kNoDate` — «нет».
- Перечисления (стабильны навсегда, `u8`): `FaithStance` 1 `Support`, 2 `Schism`, 3 `Convert` (M2), 4 `Found` (M2); `FaithStatus` 1 `official`, 2 `tolerated`, 3 `persecuted`, 4 `forbidden`; `HeadForm` 1 `Locum`, 2 `Patriarch`, 3 `Synod`; `ChurchAgenda` 1 `restore_patriarchate`, 2 `resist_control`, 3 `suppress_schism`; `ChurchPolicy` 0 `tolerance`, 1 `normal`, 2 `persecution`; `CouncilStage` 0 нет, 1 `Convened`; `CouncilOutcome` 1 `Elected`, 2 `SynodEstablished`, 3 `Vetoed`, 4 `Lapsed`, 5 `EventSet`; `DonationPurpose` 0 `general`, 1 `council`.
- Коды причин `ReligionReason` (`u16`, своё пространство): 1 `Drift`, 2 `Donation`, 3 `StanceStart`, 4 `StanceApplied`, 5 `MixedMarriage`, 6 `Council`, 7 `Veto`, 8 `Scenario`, 9…99 резерв E31, 100…199 — события E11 (ключ в данных события).

## 5. Церковь: показатели, повестка, политика, конфликт (`church.monthly`, T07)

### 5.1 Показатели

Раз в месяц (день 1) каждый показатель идёт к цели `approach` E9 с `inertia_pm = 50` (5 % разрыва, усечение к нулю, шаг ≥ 1 сырой единицы), затем зажим 0…100. Цели (пункты, `[предл.]`; `ob` — `ob_avg_pm`, `A_emp` — авторитет императора E12, 50 без кризиса):

```
T_auth  = 50 + 300‰·unity − 200‰·dependence − 10·[Locum]
T_unity = 60 − 15·[Locum] − 10·[Synod] − ob·50/1000
T_dep   = 45 + 400‰·(A_emp − 50) + 10·[Locum] + 25·[Synod] − 10·[Patriarch] − 10·[phase ≥ 2]
```

**Пример (старт, ob 80‰, A_emp 70):** `T_auth = 50 + 13,5 − 11 − 10 = 42,5`, `T_unity = 60 − 15 − 4 = 41`, `T_dep = 45 + 8 + 10 = 63`; первый месяц: авторитет `(4250 − 6000)·50/1000 = −87,5 → −87` → 59,13; единство `(4100 − 4500)·50/1000 = −20` → 44,80; зависимость `+40` → 55,40. `Breakdown` 21400 (21401…21403 — слагаемые целей).

### 5.2 Повестка (три цели, гистерезис)

```
U_restore  = [Locum]·(40 + 500‰·(authority − 40) + 300‰·(unity − 40) − 300‰·(dependence − 50))
U_resist   = 800‰·(dependence − 40) − 15·[Synod]
```

## 9. Доли вер (`religion.shares`, T06)

Месячно, в слот `province_id % 28`, для провинций со строкой **или** с владельцем, чья вера ≠ веры по умолчанию. Шаг в µ (1/1000 ‰) для каждой веры слота:

```
pull       = +1000 µ вере владельца (корона — официальной), снимается с прочих пропорционально их долям выше пола
diffusion  = (среднее соседей[f] − share[f])·5   (‰ разности × 5‰ = µ; без ProvinceGraph — 0)
persecution= policy = 2 ? −1000 µ гонимой вере, +1000 µ официальной : 0
missionary = 0 (резерв M2)
```

Затем: `total = Δ + carry`; `whole = total / 1000` (к нулю), `carry = total − 1000·whole`; **пол общины** — `pull` и `diffusion` не опускают веру ниже 20‰ (ниже пола — только события); **линия господства** — `pull` и `diffusion` не переводят веру через 500‰ ни вверх, ни вниз (господство меняют `persecution` и события); нормировка: если `Σ whole ≠ 0`, недостающие ±1‰ отдаются вере с наибольшим `|carry|` в нужную сторону (ничья — `(доля ↓, id ↑)`), её `carry` сдвигается на ∓1000. Порог: > 500‰ — господствующая, 100…500 — заметное меньшинство, < 100 — малая община; смена полосы — `ShareBand`, on-action 151. `Breakdown` 21100 (21101 владелец, 21102 диффузия, 21103 гонение, 21104 пол, 21105 линия господства, 21106 нормировка). События — `AdjustFaithShare{province, faith, delta_pm}` (222): сдвиг с нормировкой, пол не действует.

**Пример (REL-A8):** `{orthodox 600, old_believers 400}`, владелец православный, среднее соседей 900/100, гонение 2: старообрядцы `−1000 − (400 − 100)·5 − 1000 = −3500 µ` → `whole −3`, `carry −500`; православные `+3`, `carry +500` → `{603, 397}`. Без гонения (1): `−2500 µ` → `{602, 398}`, `carry ∓500`. Линия господства: `{old_believers 520, orthodox 480}`, владелец православный, политика 1, соседи 600 старообрядцев: `−1000 + (600 − 520)·5 = −600 µ` в месяц — доля сходит к 501 и **останавливается**; только гонение (2) или событие переводят провинцию в православное большинство. Сумма в строке всегда 1000.

Изменение мимо ожидаемого (эпик §3 п. 7: 2‰ и 1 %) — F7.

## 12. ИИ (T12)

### 12.1 Позиция рода без агента (`religion.ai_stance`)

Раз в 6 мес. на род (месячный слот `dynasty_id % 28` и `месяц mod 6 = dynasty_id mod 6`), кроме рода игрока и родов с агентом E17 (`is_ai_managed`), без открытого перехода и охлаждения:

```
U = zeal + grievance + estates − pressure − cost
zeal      = ai_hint(черты главы, faith_schism) (−100…100: «Раскольник» +80, «Набожный» +10, «Вольнодумец» −40)
grievance = 300‰·max(0, 50 − милость) + 10·[член рода в опале]
estates   = (средняя доля старообрядцев во владениях рода, ‰)/20
pressure  = 300‰·A_emp + 10·[policy = 2]
cost      = 40
```

«Поддержка» → `SetFaithStance{Schism}`, если `U ≥ 20`; «раскол» → `{Support}`, если `U ≤ −20`. **Примеры:** обычный глава (zeal 0), милость 50, 400‰ в вотчинах, `A_emp` 70: `0 + 0 + 20 − 21 − 40 = −41` — держится. Глава-«Раскольник», милость 20, член в опале: `80 + 9 + 10 + 20 − 21 − 40 = 58` — переход. Ожидаемо 0…2 смены за 20 лет на мир (REL-A9). `Breakdown` 21700 (21701 рвение, 21702 обида, 21703 вотчины, 21704 давление, 21705 цена, 21706 порог), три главных слагаемых — в журнал.

### 12.2 `FaithPlanner` (E17-T07, `PlannerId` 6)

Бюджет ≤ 200 WU / проход, AP: `SetFaithStance` 6, `DonateToChurch` 2. Видимость: позиции, благосклонность и доли публичны. `AiReason` (блок 400…449): 400 `StanceHold`, 401 `StanceToSchism`, 402 `StanceToSupport`, 403 `StanceCooldown`, 404 `DonateFavor`, 405 `CouncilAvoidEmperor`, 406 `DonateCouncil`, 407 `NoMoneyForDonation`, 408 `TransitionOpen`, 409 `CouncilClosed`; 410…449 резерв.
