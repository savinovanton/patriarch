(агенты в 2–3 параллельных потока). База: 972 / 103 ≈ **9,4 нед.**; по дням FTE 666 / 62 ≈ 10,7 нед. — расхождение ≈ 1 нед., в сценарии взята оценка по у.е. При темпе вдвое ниже (≈ 51 у.е./нед.) база ≈ 18,9 нед.

Итого **≈ 35 последовательных слотов** (было 25–27). При 1 слоте в день (допущение: PR + CI + слияние) — 5 нед. ежедневной работы; при наблюдаемой доле дней со слияниями за 2 недели (10 из 14) — **≈ 7 нед.** Это нижняя граница, не зависящая от числа агентов. Самый длинный критический путь эпика — E16 ≈ 57,5 дн. FTE; при одном потоке ≈ 20–30 дн. FTE/нед. это ≈ 2–3 нед., то есть критические пути эпиков сами по себе срок не задают — его задают очередь, лимиты и ожидание дизайна.

Ожидание владельца: все 8 бордов Penpot открыты — #520 (портфели, E10), #536 (вражда, E7), #579 («Влияние», E7), #584 (кризис и престол, E12), #646 (армии, E16), #698 (дипломатия, E15), #722 (Церковь, E31) — `needs:owner`; #476 (UI-D13, обновление окон под новые борды) — `status:ready`. ## 5. Явные допущения

- Объём — только заведённые issues вехи M1 (194 задачи, 972 у.е.); не учтены: два вида схем из ТЗ §5 (E14 в M2), финальный баланс и плейтест среза, окна, не разложенные на задачи, работа по будущим бордам (#476 и ответные правки).
- Оценки в днях FTE эпиков — `[предл.]` агентов, по факту не калиброваны; для прежних эпиков остаток в днях выведен через у.е. (раздел 1).
- Темп последних 2 недель включает упор в лимит подписки (13–16, 19–22, 23–25.11); «вдвое ниже» моделирует такой режим на всём остатке. Как часто лимит будет повторяться, данных нет.
- Параллелизм — не более двух Claude и одного Codex (#611); рост числа агентов срок по очереди W не сокращает.
- 1 слот очереди = 1 день со слиянием; реальная длительность W-задач (≈ 3 дн. FTE каждая) может сделать слот длиннее.
- Решения владельца, расширившие объём (#643 C, #669 C, #670 B, #693 C, #695 C, #721 B), уже в оценках эпиков; новые решения такого рода срок увеличат.
- Ожидание бордов Penpot оценено условно в 2 нед. только в пессимистичном сценарии; фактических сроков нет.
