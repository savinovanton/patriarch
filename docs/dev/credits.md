# Экран «Титры»: источники данных и авторы (UI-213)

> Статус: v1 (2026-11-10). Требование владельца (2026-11-08, [#97](https://github.com/savinovanton/patriarch/issues/97)): отдельная вкладка меню «Титры», где указаны источники данных; обязательно «Российская национальная библиотека». Лицензии — [geodata-sources.md](geodata-sources.md) и `assets/LICENSES.csv`.

## 1. Откуда берётся список

Окно ничего не знает об источниках: оно показывает список записей `credit` из `data/credits/*.pd`. Записи приходят из трёх мест:

| Откуда | Что попадает | Где лежит |
|---|---|---|
| Манифест геоданных `data-sources/geodata.manifest.json` | источники с `attribution.required = true`: название, поставщик, лицензия и **дословный** текст атрибуции | `data/credits/generated.pd` (генерирует `tools/gen_credits.py`) |
| Реестр ассетов `assets/LICENSES.csv` | строки с `attribution_required = yes`: название, автор, лицензия | `data/credits/generated.pd` |
| Явные записи | авторы игры, «Российская национальная библиотека», благодарность Natural Earth | `data/credits/credits.pd`, тексты — в `data/loc/ru/credits.pd` |

Тексты из манифеста и реестра — юридические формулировки поставщиков, их не переводят и не правят: генератор копирует их как есть. Тексты явных записей (и подписи окна) — ключи таблицы строк ([localization.md](localization.md)).

Явная запись может закрыть источник манифеста сама: `source = "<id в манифесте>"` (для ассета — `asset = "<путь в реестре>"`). Тогда генератор не создаёт для него запись, а `gen_credits.py --check` требует, чтобы текст записи содержал `attribution.text` манифеста. Так РНБ показана ровно как «Российская национальная библиотека» (`credits.rnb.name`), а изменить подпись молча нельзя.

## 2. Вид `credit`

Схема — `src/data/credits_schemas.cpp`, справочник полей — [data-reference.md](data-reference.md). Кратко: `section` (`authors` | `data` | `assets`), `order`, `name_key` или `name` (ровно одно), `text_key` или `text`, `provider`, `license`, `source`, `asset`. Пример:

```
credit "rnb" {
    section = data
    order = 10
    source = "nlr-historical-maps"
    name_key = "credits.rnb.name"
    text_key = "credits.rnb.text"
}
```

Сборка и проверка списка — `pat::content::load_credits_content` (`src/content/credits_content.cpp`, ошибки `PD115` с позицией): пустые строки, оба поля пары сразу, запись без заголовка. Мод может заменить запись, повторив её id. `contentlint` вызывает ту же сборку, поэтому ошибка в записи видна в `contentlint --strict`.

## 3. Окно

`pat::ui::CreditsWindow` (`src/ui/credits_window.cpp`, документ `apps/spike/ui/credits.rml`, стиль `credits.rcss`): панель по центру со списком, разделы «Авторы», «Источники данных», «Ассеты и шрифты» (ключи `ui.credits.section.*`), у записи — заголовок, строка «поставщик · Лицензия: …» и текст. Список собирает мост `game::credits_snapshot(loc, list)` (`src/game/credits_view.cpp`): ключи форматирует таблица строк, `name`/`text` показываются как есть. Подписи окна — `ui.credits.title|close|empty|license`. Окно по умолчанию скрыто; кнопка «Закрыть» скрывает его.

Как открыть в спайке: пункт **«Меню»** (`system`) левого меню HUD открывает и закрывает титры. Это временное место, пока нет главного меню; раскладка тоже временная (тестовый стиль, без редизайна, [ui-design.md](ui-design.md)).

## 4. Проверка в CI

`python tools/gen_credits.py --check` (job `assets`, после `check_assets.py`; те же проверки гоняет `tests/tools/test_gen_credits.py`):

1. `data/credits/generated.pd` совпадает с тем, что генератор выдаёт сейчас;
2. у каждого источника манифеста с `attribution.required` есть запись (сгенерированная или явная);
3. у каждой строки реестра с `attribution_required = yes` есть запись;
4. явные `source` / `asset` ссылаются на существующие источник и файл, а `name_key` / `text_key` — на определённые строки;
5. явная запись источника с обязательной атрибуцией содержит её текст.

Добавили источник в манифест или CC-BY-ассет в реестр: `python tools/gen_credits.py` перегенерирует файл (или напишите явную запись), закоммитьте результат. Источники со статусом `unverified` пока тоже в титрах: список меняется вместе с решением об их использовании (владелец может убрать источник из манифеста или поставить `attribution.required = false`, если набор в игру не войдёт).
