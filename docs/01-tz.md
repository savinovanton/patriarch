# Техническое задание (ТЗ) — Patriarch

> Статус: **черновик v0.1**. Параметры помечены **[предл.]**, если это моё предложение, ожидающее подтверждения.
> У каждого требования есть ID (`FR-…`, `NFR-…`). Эпики и задачи ссылаются на эти ID.

## 1. Цель и границы

**Цель:** одиночная PC-игра (Windows, затем Linux) — стратегия-симулятор династии в России начала XVIII века.

**Зафиксированные решения (из обсуждения):**

| Параметр | Решение |
|---|---|
| Режим | Только сингл |
| Платформа | PC (Windows-first), 2D политическая карта + насыщенный UI |
| Глубина экономики/населения | Средняя (сословия + несколько ресурсов, без рынка Victoria 3) |
| Технологии | C++20, собственный движок: своё ядро `sim`, свой рендер на Direct3D 11, UI на RmlUi (ADR-0001) |
| Команда | Соло, хобби / долгая разработка без дедлайнов |
| Дата старта | **1703** |
| Люди и роды | Реальные роды, **вымышленные люди** |
| Начало кризиса | «Тлеющий» кризис + несколько сценариев старта |
| Старт игрока | Готовый род **или** собственный (основание) |
| Цель партии | Выбирается игроком при старте (см. FR-GOAL) |
| Поражение | Только вымирание рода |
| Карта | Вся Россия 1700-х (Европейская часть, Урал, Сибирь, Поволжье, Украина, Прибалтика) |
| Внешний мир | События и модификаторы (Швеция, Польша, Османы, Крым — не игровые государства) |
| Длина партии | 30+ часов |
| Тон | Серьёзная драма |
| Религия | Отдельная система (см. 3.4а) |
| Моддинг | Планируется после релиза; данные открыты |
| Арт | Публичный домен / найденные ассеты / генерация / собственные рисунки |
| Пётр I | ИИ-император со своей повесткой; смертен и свергаем |
| Сценарии кризиса | Спор о наследнике; церковный раскол; рекрутские и налоговые бунты; боярский заговор |
| Война | Автобои с модификаторами, армии двигаются по карте |
| Ранги | Табель о рангах — реформа, вводимая в ходе партии |
| Казаки, старообрядцы, башкиры, калмыки | Группы населения (сословия) внутри провинций |
| Визуальный стиль | Старинная карта и гравюра XVIII века |
| Портреты | Пул гравюр и живописи без портретов конкретных лиц; персонаж получает портрет из пула по полу, возрасту, рангу |
| Стартовые роды | Ядро ~20 реальных родов (на MVP — 3–4) |

## 2. Глоссарий

- **Династия** — род, управляемый игроком или ИИ. **Член династии** — персонаж с полной симуляцией.
- **Персонаж** — человек с чертами, здоровьем, отношениями. Бывает *полный* (знатный) и *упрощённый* (слуга/второстепенный).
- **Провинция** — единица карты (уровень уезда). **Владение** — провинция, принадлежащая династии.
- **Сословие (Estate)** — агрегат населения в провинции (дворянство, духовенство, посад/купечество, крестьяне, служилые/казаки).
- **Император** — носитель престола (изначально Пётр I, ИИ-управляемый).
- **Схема (Scheme)** — длительная интрига с прогрессом и шансом раскрытия.
- **Тик** — минимальный шаг симуляции (1 игровой день).

## 3. Функциональные требования

### 3.1 Время и симуляция
- **FR-TIME-1** Игровое время идёт тиками по 1 дню; скорости 1–5 и пауза; команды допустимы на паузе.
- **FR-TIME-2** Подсистемы работают с разной частотой: ежедневно / еженедельно / ежемесячно / ежегодно (см. ADR-0002).
- **FR-TIME-3** Старт сценария: **1703-01-01**. Конец партии определяется целью игрока и условиями поражения/победы; жёсткая верхняя граница даты — **1780 [предл.]**, дальше партия уходит в режим «песочница» с ограничениями роста (ADR-0002).
- **FR-TIME-4** Симуляция детерминирована: одинаковое зерно + одинаковый поток команд = одинаковый результат.

### 3.2 Династия и персонажи
- **FR-DYN-1** Старт игрока: (а) **готовый реальный род** (стартовые владения, должности, члены рода — вымышленные люди); (б) **собственный род с нуля**: фамилия, герб/цвета, стартовый глава, стартовый капитал и малое владение (основание). Баланс обоих режимов обязателен.
- **FR-DYN-8** Поражение — **только вымирание рода** (нет живых членов рода). Смерть главы без прямого наследника передаёт линию ближайшему родственнику по закону наследования; потеря владений не завершает игру.
- **FR-DYN-2** Персонаж имеет: возраст, пол, здоровье, черты, навыки (управление, дипломатия, военное дело, интриги, образование), характер, отношения (симпатия/вражда/долг).
- **FR-DYN-3** Жизненный цикл: рождение, взросление, образование, болезни, смерть (естественная и насильственная), беременность и фертильность.
- **FR-DYN-4** Браки: поиск партии, переговоры, приданое, договорные браки между династиями, бесплодие/развод [предл.: ограниченно, с учётом роли церкви].
- **FR-DYN-5** Наследование: набор законов (майорат, минорат, назначение монархом, семейный совет); заменяемы реформой.
- **FR-DYN-6** Честь/престиж рода и легитимность: накапливаются действиями, влияют на лояльность и претензии.
- **FR-DYN-7** LOD персонажей: умершие и неактуальные персонажи архивируются в компактные записи (см. NFR-PERF-5).

### 3.3 Двор, должности, слуги
- **FR-COURT-1** Должности: придворные (воевода, казначей, глава приказа, духовник…), региональные (воевода/губернатор), военные. Назначение и отзыв, требования, бонусы.
- **FR-COURT-2** Слуги и клиентела: найм, содержание, лояльность, специализация (шпион, управляющий, учитель, телохранитель).
- **FR-COURT-3** Фракции и «партии» двора (старая знать, «птенцы гнезда Петрова», церковники, служилые) с собственными требованиями.
- **FR-COURT-4** Милость императора и патронаж: награды, опалы, ссылка, конфискация.
- **FR-COURT-5** Система рангов: на старте — родовая знатность и старшинство (наследие местничества, формально отменённого в 1682 г.); **Табель о рангах — реформа**, которую может провести император, игрок или победившая сторона. После неё карьера идёт по заслугам и службе, а не по роду; реформа меняет лояльность знати и доступ к должностям.

### 3.4 Владения и экономика (средняя глубина)
- **FR-ECO-1** Провинция: население по сословиям (агрегаты, а не отдельные люди), настроения, налогооблагаемая база, рекрутская база.
- **FR-ECO-2** Ресурсы: ~8–12 видов [предл.] (зерно, соль, пушнина, железо, лес, пенька/лён, ткани, медь/серебро …); добыча/производство в провинции.
- **FR-ECO-3** Здания и развитие провинции (мануфактуры, дороги, церкви, крепости).
- **FR-ECO-4** Казна: доходы (налоги, пошлины, торговля), расходы (содержание армии, двора, слуг, строительство), долги.
- **FR-ECO-5** Упрощённая торговля: торговые маршруты и региональные цены, ежемесячный расчёт потоков; без полного рынка по каждому товару.
- **FR-ECO-6** Реформы и политика (налоговая, крепостная, рекрутская) влияют на сословия и бунтарство.
- **FR-ECO-7** Особые группы населения — **казаки, старообрядцы, башкиры, калмыки** и др. — представлены как дополнительные агрегаты внутри провинций (как сословия): у каждой свои настроения, требования, вклад в рекруты и налоги, связь с религией и бунтами. Отдельных фракций-акторов с армиями нет; их вспышки выражаются через бунты и события.

### 3.4а Религия и Церковь (отдельная система)

Сеттинг: Патриарх Адриан умер в 1700 году, и по воле Петра новый патриарх не избирался — церковью управляет местоблюститель (исторически Стефан Яворский); реформа церкви и расколы — часть кризиса. Это даёт игре тему, созвучную названию.

- **FR-REL-1** В игре есть **официальная Церковь** как политический актор со своей иерархией, землями, доходами и фракциями (иерархи, чёрное/белое духовенство). Видны вакансия патриаршества и борьба за него/за синодальное устройство.
- **FR-REL-2** Каждая династия выбирает **позицию** по отношению к Церкви: (а) **поддержать** официальную Церковь (легитимность, поддержка духовенства и части крестьян/посада, ограничения и обязательства); (б) **отделиться** от неё (раскол/старообрядчество, свой толк; риск репрессий, но поддержка гонимых сословий); (в) **принять другую веру/конфессию** (католичество, лютеранство, ислам, буддизм, язычество и т.д. — доступность зависит от региона и культуры владений); (г) **основать собственный «столп» Церкви** (своя конфессия).
- **FR-REL-3** Основание собственной Церкви: стоимость (престиж, казна, духовенство), выбор догматов/черт из набора (влияют на модификаторы, браки, схемы, отношение сословий), наименование и символика, иерархия и должности.
- **FR-REL-4** Конфессия влияет на: лояльность сословий и провинций, легитимность претензий, ограничения на браки, казус белли (ересь/раскол), события, доходы (церковные земли, секуляризация), набор доступных схем.
- **FR-REL-5** Религиозная политика династии меняется и имеет последствия по времени (охлаждение, давление, гонения, диалог).
- **FR-REL-6** Религия ИИ-династий: ИИ выбирает позицию по характеру, выгоде и давлению; конфессии могут объединяться/распадаться.

### 3.5 Армия и война
- **FR-MIL-1** Армии: состав, мораль, содержание, полководец; перемещение по графу провинций.
- **FR-MIL-2** Снабжение — упрощённое (лимит снабжения провинции).
- **FR-MIL-3** Бои — автоматическое разрешение с модификаторами (местность, полководец, мораль, численность).
- **FR-MIL-4** Осады и крепости.
- **FR-MIL-5** Рекрутский набор через владения и сословия; ограничение по числу армий (ADR-0002).

### 3.6 Дипломатия и другие династии
- **FR-DIP-1** Отношения между династиями: мнение, долги, союзы, браки-договоры, вражда.
- **FR-DIP-2** Претензии на земли и престол; казус белли; объявление войны владениям.
- **FR-DIP-3** ИИ-династии (≈40–100 [предл.], из них ~20 крупных; реальные роды, вымышленные люди) ведут себя целенаправленно: расширяются, женят, интригуют, выбирают сторону и веру.
- **FR-DIP-4** **Внешний мир** (Швеция, Польша-Литва, Османская империя, Крым, Персия, Китай и т.д.) — **не игровые государства**: представлен событиями, внешними угрозами, модификаторами и «внешним фронтом» (шкалы давления на границе, война/мир как состояние), который влияет на стабильность, рекрутчину и казну. Отдельных династий, экономики и карт границ у внешних держав нет.

### 3.7 Интриги и схемы
- **FR-INT-1** Схемы: подкуп, шпионаж, компромат, соблазн, отравление, заговор против должностного лица, заговор против императора.
- **FR-INT-2** Каждая схема: исполнитель, цель, прогресс, шанс раскрытия, последствия раскрытия.
- **FR-INT-3** Контрразведка: способности слуг/членов рода раскрывать схемы.
- **FR-INT-4** Заговоры могут быть коллективными (присоединение других династий, взносы поддержки).

### 3.8 Престол, переворот, гражданская война
- **FR-THR-1** Шкала **стабильности империи** (0–100). Источники падения: война, налоги, рекрутчина, реформы, смерти наследников, раскрытые заговоры.
- **FR-THR-2** ИИ императора (Пётр I): политическая повестка (реформы, Северная война, флот, чистки, церковная политика), реакция на угрозы. Император **смертен** (болезнь, покушение, смерть вне партии игрока) и **свергаем** (переворот); он может и сам инициировать чистку или опалу рода. После смерти или свержения престол оспаривается по законам наследования и претензиям.
- **FR-THR-3** Претензии на престол: основания, поддержка фракций, легитимность.
- **FR-THR-4** Эскалация: интрига → дворцовый переворот → гражданская война; чёткие пороги и тултипы.
- **FR-THR-5** Престол как конечная цель — только один из путей (см. FR-GOAL). Лояльный путь: империя пережила кризис при вашем содействии; узурпаторский: член вашего рода на престоле; иные финалы [предл.: изгнание, монастырь, сильное, но не царствующее положение рода].
- **FR-THR-6** Тлеющий кризис: четыре стартовых сценария — разные источники напряжения и стартовые значения стабильности; дальше кризис развивается динамически и не запускается одним скриптовым событием:
  1. **Спор о наследнике** — царевич и другие претенденты, разногласия двора о преемнике;
  2. **Церковный раскол** — вакансия патриаршества, давление на старообрядцев, спор о синодальном устройстве;
  3. **Рекрутские и налоговые бунты** — Северная война выжимает ресурсы, бунтуют сословия и казаки;
  4. **Боярский заговор** — старая знать против «птенцов гнезда Петрова», заговор в верхах.

### 3.8а Цели партии
- **FR-GOAL-1** При старте игрок выбирает цель: (а) **пережить кризис** до даты/условия (лояльный путь); (б) **занять высшую должность** при дворе; (в) **набрать очки династии** (богатство, титулы, потомство, влияние, вера); (г) **занять престол** (узурпация); (д) **песочница без цели**.
- **FR-GOAL-2** Цели можно комбинировать/менять в ходе партии с последствиями для итогового счёта.
- **FR-GOAL-3** Итоговый экран: счёт династии, летопись рода, ключевые решения и последствия.

### 3.9 События и повествование
- **FR-EVT-1** Система событий: триггеры, варианты, последствия, цепочки, вес/кулдауны.
- **FR-EVT-2** Исторические «якоря» (опционально включаемые): Северная война, Полтава, дело царевича Алексея и т.п.
- **FR-EVT-3** Данные событий вне кода (файлы контента), валидация при загрузке.

### 3.10 UI/UX
- **FR-UI-1** Политическая карта провинций, режимы карты (владельцы, династии, лояльность, сословия, ресурсы).
- **FR-UI-2** Окна: династия (древо), персонаж, провинция, двор/должности, казна, армия, дипломатия, интриги, события, журнал.
- **FR-UI-3** Вложенные тултипы с разбором модификаторов («почему это значение»).
- **FR-UI-4** Уведомления с приоритетом и фильтрами; автопауза на важных событиях.
- **FR-UI-5** Локализация RU (основной) и EN [предл.]; кириллица и склонения/плюрализация (ICU MessageFormat или свой плюрализатор).
- **FR-UI-6** Масштабируемый UI (DPI, разрешения, UI-scale), клавиатурные шорткаты.
- **FR-UI-7** Стиль: старинная карта и гравюра XVIII века — пергамент, засечные шрифты, гравированные иконки и рамки; тема UI задаётся стилями RmlUi (`.rcss`).
- **FR-UI-8** Портреты персонажей берутся из пула гравюр и живописи **без портретов реальных лиц**; пул размечен по полу, возрасту, рангу и роду занятий; один и тот же персонаж всегда получает один и тот же портрет (по ID). Реестр ассетов с лицензиями обязателен.

### 3.11 Сохранения и данные
- **FR-SAVE-1** Сохранение/загрузка полной партии, версионирование формата, миграции.
- **FR-SAVE-2** Автосохранения; быстрые сохранения.
- **FR-DATA-1** Весь контент (провинции, династии, события, здания, черты) — в файлах данных, не в коде.

## 4. Нефункциональные требования

### 4.1 Производительность (критично)
- **NFR-PERF-1** UI не зависит от симуляции: ≥ 60 FPS при любой скорости; цель по минимальному железу [предл.]: 4-ядерный CPU 2018 г., 8 ГБ ОЗУ, встроенная/слабая дискретная графика.
- **NFR-PERF-2** Бюджеты тика на **максимальном состоянии партии** [предл.]: дневной тик ≤ **8 мс** (p95), недельный ≤ 30 мс, месячный ≤ 120 мс, годовой ≤ 400 мс, скорость 5 ≥ 20 дней/сек.
- **NFR-PERF-3** Рост времени тика с игровой датой должен быть **ограничен** (разница «год 1» vs «год 60» ≤ 2× при тех же размерах мира).
- **NFR-PERF-4** Память партии ≤ 1.5 ГБ в конце партии [предл.].
- **NFR-PERF-5** Размер живой симуляции ограничен *по дизайну*: ≤ ~5 000 полных персонажей, ≤ ~300 армий, ≤ ~400 провинций (вся Россия), ≤ ~100 династий [предл.]; всё остальное архивируется или агрегируется. Партия 30+ часов делает это ограничение обязательным, а не пожеланием.
- **NFR-PERF-6** Загрузка партии ≤ 15 с, сохранение ≤ 5 с (в фоне, без фриза UI).
- **NFR-PERF-7** CI запускает бенчмарки и **блокирует регрессию** > 10% на ключевых путях; есть стресс-сценарий «поздняя партия» с ×3 нагрузкой.

### 4.2 Качество и поддержка
- **NFR-DET-1** Детерминизм ядра: целочисленная/фиксированная арифметика в симуляции, никаких `HashMap`-итераций и float в расчётах, влияющих на состояние.
- **NFR-TEST-1** Ядро покрыто юнит-тестами и property-тестами; golden-тесты на реплеях (seed + команды → хеш состояния).
- **NFR-TEL-1** Встроенная телеметрия времени подсистем (оверлей в dev-сборке), трассировка (Tracy).
- **NFR-MOD-1** Данные и правила отделены от кода; формат данных открыт и документирован; моддинг открывается после релиза (подгрузка пользовательского контента из папки, порядок/конфликты, валидатор).
- **NFR-COMPAT-1** Windows 10/11 x64 на релизе (Direct3D 11); Linux — этап после релиза через Proton или отдельный бэкенд рендера [предл.].

## 5. Определение MVP (вертикальный срез)

MVP-срез считается готовым, когда:
1. Играбельная карта из **~20 провинций**, **3–4 династии** (одна игрока).
2. Время, скорости, ежемесячная экономика, казна.
3. Персонажи: рождение, браки, смерти, наследование.
4. 5–7 должностей, 2 вида схем, 20+ событий.
5. Император-ИИ и шкала стабильности, один сценарий переворота.
6. Сохранение/загрузка, базовые окна, тултипы.
7. Бюджеты производительности из NFR-PERF-2 выполняются на сгенерированном стресс-состоянии, имитирующем «год 60».

## 6. Риски (топ)

| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| Объём UI съедает проект | Высокая | Высокое | Раннее решение по UI-стеку (спайк), data-driven окна, MVP на 8–10 окнах |
| Скоуп-крип (все системы сразу) | Высокая | Высокое | Вертикальные срезы, жёсткий MVP, порядок эпиков по зависимостям |
| Деградация производительности в поздней партии | Средняя | Высокое | ADR-0002, бюджеты, бенчмарки в CI с первого дня |
| Нехватка контента (события, лица, текст) | Высокая | Среднее | Процедурные шаблоны событий, ограниченный набор исторических якорей |
| Историческая точность / чувствительность | Средняя | Среднее | Явная альтернативная история, вымышленные династии там, где нужно |
| Выгорание соло-разработчика | Средняя | Высокое | Короткие вехи, играбельность каждые 2–4 недели |
| «Свой движок» поглощает время, игра не появляется | Высокая | Высокое | Свои только `sim`, карта и рендер; UI/шрифты/аудио — готовые; MVP-первым играбельным кусочком |
| Вся Россия 1700-х + 30+ часов партии: рост сущностей и контента | Высокая | Высокое | Лимиты ADR-0002, укрупнённые провинции вне ядра (Сибирь), шаблонные события |
| Религиозная система разрастается | Средняя | Среднее | Набор догматов фиксированный, конфессии — данные; MVP только «поддержка/раскол» |
| Использование арта из разных источников (лицензии) | Средняя | Среднее | Реестр ассетов с лицензиями, предпочтение public domain / CC0 |

## 7. Критерии приёмки (общие)

- Все требования имеют тесты или демонстрационный сценарий.
- Бенчмарки NFR-PERF выполняются на целевом минимальном железе.
- Реплей-тест детерминизма проходит на Windows и Linux (даёт одинаковый хеш).
