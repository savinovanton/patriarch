Попытка отключить `require_opposite_sex` или `forbid_same_house` отвергается общей проверкой правил с позицией ошибки данных (решение владельца 2026-11-16, E8-T08); инварианты мира не расширяются.
- [#600](https://github.com/savinovanton/patriarch/issues/600): пауза после согласия — 0 дней, срок свадьбы после ранней разрешённой даты — 365 дней; для детей ранняя дата определяется брачным возрастом. Смена рода до ответа отменяет переговоры с отдельной причиной и сохранением исходных родов и расхода (решения владельца 2026-11-17, E8-T09).
- [#306](https://github.com/savinovanton/patriarch/issues/306): свадебное приданое, вдовья доля и возврат перечисляются по паре `DowryOut`/`DowryIn`, выпущенной в E8-T03. Свадебный перевод может создать долг, а при насыщении применяется наименьшая доступная сумма (модель §5.2). Проверка обеспеченности при отправке касается расхода на посредника.
- [#491](https://github.com/savinovanton/patriarch/issues/491): при малолетнем первом претенденте временная власть переходит следующему взрослому; если взрослых нет — обычное регентство малолетнего без окончательного титула. Попытка узурпации чужеродной матерью вызывает отдельное событие E11, без прямой смены главы; контент исхода создаётся отдельно.

### Отношения и вражда внутри рода (E7-T25, [#516](https://github.com/savinovanton/patriarch/issues/516))

4. **Тон контента** — рейтинг 12+ (с 2026-11-16 — **16+**, #594), без насилия над родственниками в M1 (оно остаётся M2).

Решения агента (спецификация [house-relations-model.md](dev/house-relations-model.md), GDD 01 §8.4; пересматриваются при ревью): уровень хранится в разреженной таблице пар `FeudTable` как кэш с гистерезисом (истина — мнения E7-T17); ни одного броска ГСЧ; причины — коды `OpinionReason` 40…79; теги команд 22…24, раздел сейва 8, часть хеша 38, схема +1 на момент слияния; деньги — статья 106 без новых кодов; on-action 26…28; задачи E7-T26…T37 ([эпик E7](epics/E07-characters-dynasty.md) §5.1), E7-T26 в очереди W после E10-T03.
