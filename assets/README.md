# Ассеты и реестр лицензий

Любой файл в `assets/` (шрифты, гравюры, иконки, звуки, музыка, текстуры) **обязан** быть записан в [`LICENSES.csv`](LICENSES.csv). Это проверяет `tools/check_assets.py` (локально и в CI): неучтённый файл или запись без файла — ошибка.

## Колонки

| Колонка | Смысл |
|---|---|
| `path` | Путь относительно `assets/`, с `/` (например `fonts/serif/Example-Regular.ttf`) |
| `title` | Название работы |
| `source_url` | Где взято (обязательно, кроме собственных работ) |
| `license` | Идентификатор из списка ниже |
| `author` | Автор / правообладатель (обязательно, если нужна атрибуция или работа собственная) |
| `attribution_required` | `yes` / `no` |
| `checked_on` | Дата проверки лицензии, `ГГГГ-ММ-ДД` |
| `notes` | Свободный комментарий (для `Commercial` — ссылка на подтверждение права) |

## Допустимые лицензии

`CC0-1.0`, `Public-Domain`, `CC-BY-4.0`, `CC-BY-3.0`, `CC-BY-SA-4.0`, `MIT`, `Apache-2.0`, `OFL-1.1` (шрифты), `Original` (собственная работа), `Commercial` (куплено/заказано, подтверждение в `notes`).

**Запрещены** для коммерческого проекта: `CC-BY-NC*` (некоммерческие) и `CC-BY-ND*` (без производных). Если сомневаетесь в статусе «общественного достояния» — укажите источник и обоснование в `notes`.

## Данные для объёмной карты (ADR-0003)

Карты высот (DEM), реки, береговые линии и текстуры материалов поверхности — тоже ассеты и тоже заносятся в реестр, **с точной версией набора данных** и страницей лицензии. Допустимы наборы в общественном достоянии или с лицензией, разрешающей коммерческое использование (с атрибуцией, если нужна); перед включением проверяйте условия конкретного набора. Для сгенерированных из них производных файлов (`mapgen`) указывайте исходный набор в `notes`.

## Правила

1. Сначала проверяем лицензию, потом кладём файл и запись **в одном коммите**.
2. Для `CC-BY*`: атрибуция попадёт в экран «Благодарности» — поэтому `author` обязателен.
3. Сгенерированные ИИ изображения регистрируем как `Original` с указанием инструмента в `notes`; перед релизом их юридический статус проверяется отдельно.
4. Пустой каталог (только `LICENSES.csv` и этот файл) — нормальное состояние на старте.
